# ADR 0001：视频项目采用浅层、面向人的制作目录

## Decision

视频 Skill 不采用 Research 风格的结构化项目数据库，也不以复杂阶段目录组织视频项目。

项目根目录保留 `VIDEO.md`。视频制作内容统一位于 `video/`：

- `script/` 保存视频脚本层；
- `materials/` 保存跨镜头复用内容；
- `shots/<shot-id>/` 保存单镜头定义、Prompt 版本和生成结果；
- `edit/` 仅在整片后期时创建；
- `.tmp/` 保存一次性生成包，并在结果导回后删除。

小说、章节、世界观和其他上游内容由其他 Skill 或项目结构拥有，视频 Skill 只保存视频化转换结果。

## Rationale

用户需要能够直接浏览和理解项目，不希望为了 AI 生成而维护复杂机器状态、重复版本树或大量预建目录。外部 AI 图片/视频平台仍可由用户实际操作，因此 Prompt 与参考素材需要能够一次性打包，但该包不应成为长期项目源。

## Consequences

- Git 承担长期文本版本历史。
- Prompt 可以在镜头目录中保留少量版本。
- Take 直接归档到对应镜头目录。
- 只有真实复杂项目才在 `shots/` 内增加章节等更深层组织。
