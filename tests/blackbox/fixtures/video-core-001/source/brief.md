# 视频 brief

## 目标

制作一支 12–15 秒、16:9、无对白的短视觉片。

用户会在外部图片 / 视频模型中亲自完成实际生成。Agent 负责整理视频项目、正式提示词和一次性生成包。

## 故事

同一位年轻档案修复师 CHR01 在同一间旧档案室 LOC01 中完成三个连续镜头：

1. CHR01 走到木桌前，注意到桌上的一枚旧黄铜钥匙。
2. CHR01 用右手拿起钥匙，在窗光下观察。
3. CHR01 把钥匙放进外套内侧口袋，转身离开木桌。

没有对白。声音不是本次第一阶段的制作重点。

## 视觉方向

- 写实摄影；
- 温暖但不过度复古；
- 午后自然窗光；
- 旧档案纸、深色木材、黄铜形成主要材质关系；
- 画面克制，不使用奇幻特效；
- 不需要复杂手持摄影。

## 角色设计授权

用户明确授权 Agent 在上述视觉方向内决定 CHR01 的具体面部、发型、服装和颜色。

要求：

- 角色一眼可辨认；
- 服装适合档案修复工作；
- 三个镜头保持同一人物和同一基础服装；
- 不需要表情表、动作库或多套服装。

## 场景设计授权

用户明确授权 Agent 设计 LOC01 的具体空间、家具、材质与窗光方向。

要求：

- 同一档案室贯穿三个镜头；
- 木桌、窗、主要档案柜位置要稳定；
- 午后主光方向稳定；
- 不需要多个 day/night 状态。

## 长期参考要求

在开始视频生成前，用户要求先得到：

- CHR01 严格人物四视图；
- LOC01 严格场景四视图。

用户会用 Agent 打包好的图片生成 Prompt 在外部工具中生成，再把结果带回来。

第一轮只需要准备这两个图片任务。

在这两个四视图真实返回并通过审片以前，**不要提前打视频生成包**。

## 项目组织要求

- 保持人类可读浅目录；
- 不创建项目数据库；
- 不创建一级 `audio/`、`delivery/`、`assets/`；
- 不创建 `STORY.md`；
- 不为了模板完整创建空文件 / 空目录；
- 临时生成包必须位于项目自己的 `.tmp/`，用完删除。

## 当前用户期望的交付

本轮会话结束时，用户希望拿到一个自包含的一次性**图片生成包**，里面能直接看到：

- 本次为什么先生成 CHR01 / LOC01；
- CHR01 正式生图提示词 + 严格人物四视图要求；
- LOC01 正式生图提示词 + 严格场景四视图要求；
- 推荐生成顺序；
- 返回文件名；
- 返回后下一步。

本轮不要求真正生成任何图片或视频。
