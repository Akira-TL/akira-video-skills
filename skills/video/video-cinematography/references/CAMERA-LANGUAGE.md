# 摄影语言

用于把镜头意图转换成可执行的景别、机位、镜头运动、透视、景深和焦点设计。

目标不是堆摄影术语，而是让摄影选择真正服务信息、人物关系、产品可读性和情绪。

## 1. 景别先回答“观众要看什么”

常见景别：

- 大全景（Extreme Wide Shot, EWS）：环境 / 规模 / 人物与空间关系；
- 全景（Wide Shot, WS）：完整人物与主要动作；
- 中景（Medium Shot, MS）：人物动作 + 表演；
- 近景（Close-Up, CU）：表情 / 关键信息；
- 特写（Extreme Close-Up, ECU）：眼睛、手、产品细节等极局部信息。

景别不是固定套餐。

切近一档应该带来新的信息或情绪；如果近景和中景表达完全一样，就不需要为了“专业”多做一镜。

## 2. 景别与焦段不是一回事

“全景 / 近景”描述主体在画面里的大小；“广角 / 长焦”描述透视与视野。

同样一个中景：

- 使用较广焦段并靠近人物 → 透视更强、前后距离夸张；
- 使用较长焦段并后退 → 空间压缩、背景更靠近主体。

不要把“wide shot”误当成“wide-angle lens”。

## 3. 焦段只在真的影响画面时记录

需要稳定透视 / 产品形变 / 人物脸型时，可以在 `SHOT.md` 写全画幅等效焦段或焦段范围。

不需要时只写可见效果，例如：

- 自然人眼透视；
- 轻微广角、空间感明显；
- 长焦压缩背景；
- 微距产品细节。

AI 模型对精确“35 mm / 50 mm / 85 mm”术语的响应可能因模型变化；如果模型适配器 / 官方资料没有证明精确焦段可控，就把目标透视效果作为核心，不把数字当硬性保证。

## 4. 人脸与产品的畸变风险

极广角近距离拍摄容易：

- 拉长脸；
- 放大鼻子 / 手；
- 让产品边缘变形；
- 改变工业比例。

人物身份或真实产品结构是高优先级时，除非设计明确需要夸张透视，否则避免“超广角 + 非常近”的组合。

产品特写尤其优先保证结构可读，不为了夸张冲击力牺牲真实比例。

## 5. 机位高度与角度

机位至少考虑：

- 视平高度；
- 高机位；
- 低机位；
- 顶视；
- 俯视 / 仰视程度；
- 是否倾斜构图。

角度要服务内容：

- 高机位可以强调脆弱 / 空间；
- 低机位可以强调力量 / 规模；
- 顶视适合布局 / 图形关系；
- 倾斜构图适合失衡 / 紧张。

不要因为“更电影”让每个镜头都使用极端角度。

## 6. 推拉、变焦与摇移要区分

### 推近 / 拉远（Dolly In / Out）

摄影机物理移动，透视关系随距离变化。

常用于：

- 发现信息；
- 强化情绪；
- 揭示 / 离开空间。

### 变焦（Zoom）

摄影机位置不变，改变焦距和画面范围。

和推镜产生的空间感不同。

如果模型容易混淆，提示词直接写：

- `摄影机物理向主体靠近，背景透视随距离变化`；

而不是只写“zoom in”。

### 横移（Truck / Track）

摄影机横向移动，适合：

- 跟随人物；
- 揭示遮挡后的信息；
- 建立空间关系。

### 摇镜 / 俯仰（Pan / Tilt）

摄影机位置基本不变，只改变朝向。

适合跟随视线、动作或从一个信息转到另一个信息。

### 环绕 / 弧线（Orbit / Arc）

适合展示人物关系、空间或产品立体性，但会显著增加结构与连续性风险。

真实产品缺少完整多角度参考时，不为了“高级感”默认做大幅环绕。

## 7. 锁定机位也是主动选择

以下情况固定机位往往更合适：

- 产品真实结构优先；
- 精细动作已经很复杂；
- 对白 / 表演需要稳定观察；
- 画面本身有强构图；
- 运镜没有额外信息作用。

“镜头不动”不是缺少导演设计。

## 8. 手持与稳定运动

手持（Handheld）可以提供：

- 主观感；
- 紧张；
- 现场感。

但应区分：

- 有控制的轻微手持；
- 模型随机抖动。

如果目标只是“自然”，不要直接要求剧烈手持；先说明幅度和情绪目的。

稳定器 / 滑轨感则适合更平滑的商业、空间展示或人物跟拍。

## 9. 景深与焦点

浅景深适合：

- 强调人物 / 产品；
- 隔离背景；
- 焦点转移。

但过浅景深会让：

- 产品一部分失焦；
- 两个人无法同时读清；
- 手物操作难看清；
- 模型产生不自然焦点呼吸。

如果画面需要同时看清人物和产品，不要为了“电影感”默认极浅景深。

## 10. 焦点转移

焦点转移（Rack Focus）只有在注意力真的从 A 转到 B 时使用。

例如：

CHR01 面部清晰
→ 焦点转到前景 PROD01

不要和大幅摄影运动、多人复杂动作同时堆叠。

## 11. 构图

构图优先保证：

- 主体可读；
- 视线空间；
- 动作方向有空间；
- 产品 / 道具不被无意遮挡；
- 多画幅安全区（适用时）；
- 相邻镜头能自然切。

三分法、中心构图、对称、负空间等只是工具，不是固定规则。

## 12. 人物视线与留白

人物看向画面一侧时，通常给视线方向留出空间。

需要表达压迫 / 封闭时可以故意减少视线空间，但要是有意构图，而不是随机裁切。

## 13. 产品摄影

产品镜头额外检查：

- 轮廓是否清楚；
- 关键操作部位是否可见；
- 反光 / 高光是否遮挡 Logo / 结构；
- 焦点是否落在核心卖点；
- 运镜是否会暴露没有官方参考的未知角度。

产品结构优先于炫技摄影。

## 14. 一个镜头的摄影复杂度

AI 视频里，一个镜头优先只有一个主要摄影运动。

例如：

- 缓慢推近；
- 横向跟拍；
- 固定机位 + 焦点转移。

如果同时要求：

环绕 + 推近 + 变焦 + 俯仰 + 焦点转移，

先问这些变化是否真的都服务叙事；多数情况应该简化。

## 15. 摄影与动作谁优先

当人物 / 产品动作已经很复杂时，摄影优先简化。

当主体动作非常简单时，摄影可以承担更多信息揭示。

不要让摄影与主体同时竞争复杂度。

## 16. 跨镜头摄影连续性

相邻镜头不需要使用同一焦段，但明显变化应有作用。

检查：

- 是否突然从极广角跳极长焦却没有信息变化；
- 人物脸型 / 产品比例是否因透视变化造成身份不稳定；
- 轴线和视线是否仍成立；
- 动作切点是否匹配。

## 17. 写进 SHOT.md 的最小摄影信息

复杂镜头可以记录：

```text
景别：中近景
机位：人物视平高度，动作轴南侧
透视：自然，避免广角脸部畸变
运动：缓慢物理推近
焦点：CHR01 眼睛；动作结束时保持人物清晰
目的：从普通观察逐渐进入角色意识到问题的瞬间
```

简单镜头可能只需要：

```text
固定中景。
```

## 18. 模型适配

模型专用摄影术语和当前支持能力由模型适配器负责。

如果官方 / 实际模型对某术语理解不稳定，优先把术语翻译成：

- 摄影机是否移动；
- 向什么方向；
- 速度；
- 主体在画面怎样变化；
- 透视 / 焦点希望产生什么可见效果。

## 完成标准

摄影决定能够解释“为什么这样拍”和“观众会因此看到什么”；专业术语用于减少歧义，而不是装饰提示词。
