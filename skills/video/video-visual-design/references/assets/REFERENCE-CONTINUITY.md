# 长期参考连续性

当同一个角色、地点、产品或道具需要跨多轮生成持续复用时使用。

## 1. 已验收素材是后续基准参考

一旦某个长期素材已经通过 `video-review` 并归档，例如：

- `CHR01_identity.png`；
- `CHR01_four-view.png`；
- `LOC01_four-view.png`；
- `PROD01_official-front.png`；
- `CHR01_voice-reference.wav`；

后续生成同一身份 / 结构时优先引用这些已验收素材，不重新只靠文字描述随机生成。

## 2. 设计文件仍是上位约束

基准参考是已经验收的视觉 / 声音实例，不取代：

- `CHR01_design.md`；
- `LOC01_design.md`；
- 产品事实；
- 声音设计。

如果某张参考图偶然遗漏设计中的细节，后续不能因为“参考图没画出来”就自动删除设计要求。

## 3. 新状态从同一身份派生

例如：

基础人物身份
→ costume-b
→ wet
→ damaged

新状态应同时继承：

- 已验收基础身份参考；
- 当前状态设计 / 提示词。

不要为每个状态从纯文本重新创建一个“相似角色”。

## 4. 新角度从已有空间 / 结构派生

同一地点新增观察角度时，优先复用：

- 已验收场景四视图；
- 场景设计；
- 空间关系。

同一产品新增镜头角度时优先复用官方结构素材，不让新的 AI 图变成新的结构来源。

## 5. 不自动替换基准参考

新生成图更漂亮，不代表应该自动替换长期身份参考。

只有当：

- 当前参考确实有结构 / 身份问题；
- 当前设计正式改变；
- 用户明确选择新的视觉方向；

才把新素材作为新的长期基准。

替换前先由 `video-review` 对照正式设计和已有镜头检查影响。

## 6. 多个参考的职责

允许一个对象同时有多个长期参考，但每个参考要有明确职责，例如：

- `CHR01_identity.png` — 面部 / 发型；
- `CHR01_four-view.png` — 全身比例和服装结构；
- `CHR01_costume-b.png` — 新服装；
- `CHR01_voice-reference.wav` — 基础音色。

不要保留五张“都大概负责人物身份”的相互竞争图片。

## 7. 失败模式

如果同一个角色越生成越不像：

1. 检查当前生成包是否真的带了已验收身份参考；
2. 检查是否一次上传了多个互相冲突的人脸；
3. 检查提示词是否重新描述了不同的发型 / 年龄 / 服装；
4. 检查当前状态是否被误当成新身份；
5. 必要时回到设计和四视图，而不是继续累积“近似参考”。

## 完成标准

同一个对象跨多轮生成仍能追溯到稳定设计和已验收基准参考；新的状态 / 角度是在同一身份上变化，而不是每轮重新随机设计。
