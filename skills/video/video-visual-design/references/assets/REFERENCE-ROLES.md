# 参考素材职责

参考素材进入生成前，必须先明确它负责传递什么，不把“上传了参考”当成模型应该自动理解全部意图。

## 1. 人物身份参考

主要负责：

- 面部身份；
- 发型；
- 身体比例；
- 稳定配件；
- 基础服装（如果当前身份参考包含并需要保持）。

默认不负责：

- 当前镜头动作；
- 摄影机运动；
- 场景；
- 临时表情；
- 临时道具。

## 2. 服装 / 状态参考

主要负责：

- 当前服装；
- 材质；
- 颜色；
- 当前剧情状态，例如 wet / damaged。

必须同时继承基础角色身份，不把“服装图里脸不清楚”解释成可以重新设计人物。

## 3. 场景参考

主要负责：

- 空间结构；
- 门窗 / 家具；
- 材质；
- 主色；
- 主光方向；
- 视觉锚点。

默认不负责：

- 人物身份；
- 临时动作；
- 只属于某一镜头的一次性烟雾 / 破坏；
- 产品结构。

## 4. 产品官方参考

主要负责：

- 当前具体型号的工业结构；
- 部件数量；
- 颜色；
- Logo / 型号位置；
- 官方可见细节。

不负责：

- 场景；
- 镜头动作；
- 创意风格；
- 未被官方资料证明的功能。

## 5. 道具结构参考

主要负责：

- 形状；
- 比例；
- 连接关系；
- 当前状态。

陌生机械还要结合机制说明，不让一张静态图自动定义运动方式。

## 6. 动作参考视频

主要负责：

- 身体动作；
- 节奏；
- 动作路径；
- 交互时机。

默认不负责：

- 演员身份；
- 服装；
- 场景；
- 产品外观。

如果当前模型无法明确限制参考视频只迁移动作，优先裁切 / 简化参考，或换成动作关键帧 / 文字描述，不要接受身份污染。

## 7. 摄影参考视频

主要负责：

- 摄影机路径；
- 推拉摇移；
- 速度；
- 构图变化；
- 焦点变化（如果当前模型能够表达）。

默认不负责片中人物、场景和服装。

## 8. 风格参考

主要负责：

- 材质语言；
- 色彩；
- 光线；
- 画面质感；
- 艺术媒介。

风格参考中的人物脸、Logo、品牌产品和偶然场景物件不自动成为当前项目事实。

## 9. 声音参考

角色声音参考主要负责：

- 基础音色；
- 年龄感；
- 音域；
- 发音 / 节奏特征。

默认不负责：

- 当前台词内容；
- 当前情绪强度；
- 当前房间混响。

当前文本与情绪由 `video-script` / `video-audio` 单独定义。

## 10. 一个素材可以有多个职责，但要明确

例如人物四视图可以同时负责：

- 身份；
- 身体比例；
- 服装结构。

但不要因为“一个文件信息很多”就让它隐式承担场景、摄影、动作等所有职责。

## 11. 冲突参考

如果两份参考对同一个职责给出不同答案，不能同时无说明上传并让模型自己选。

先判断：

1. 哪一份是当前正式设计 / 已验收基准；
2. 另一份是否只是动作 / 摄影 / 风格参考；
3. 是否可以裁掉冲突信息；
4. 是否需要生成新的无冲突中间参考；
5. 是否应该只保留一个 canonical reference。

## 12. 最小充分集合

生成批次不是“参考越多越稳”。

优先使用：

- 一个明确人物身份基准；
- 一个当前状态 / 服装补充（需要时）；
- 一个场景结构基准；
- 一个产品结构基准；
- 一个动作 / 摄影参考（需要时）。

具体数量由任务和模型能力决定，核心是每份参考有不冲突的职责。

## 13. 批次内写法

`Bxxx/README.md` 或当前 task Prompt 中直接说明：

```text
CHR01_identity.png — 人物身份 / 发型 / 基础比例
CHR01_costume-b.png — 当前服装
LOC01_four-view.png — 场景空间
action-reference.mp4 — 只参考动作节奏，不参考演员身份 / 服装 / 背景
PROD01_official-front.png — 产品工业结构
```

## 完成标准

每一份输入参考都有清楚职责；同一职责不存在未经处理的冲突；动作 / 摄影 / 风格参考不会偷偷改写人物身份、产品结构或场景事实。
