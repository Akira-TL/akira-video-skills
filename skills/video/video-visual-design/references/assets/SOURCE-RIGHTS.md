# 素材来源与使用边界

本文件用于避免把“能找到 / 能下载 / 能生成”误当成“可以在当前项目里自由使用和交付”。它不是法律意见，也不要求建立复杂版权数据库。

## 1. 什么时候需要记录来源

以下素材至少保留来源 pointer 或最短说明：

- 用户提供的人物 / 真人照片；
- 品牌官方产品图、Logo、宣传物料；
- 第三方摄影、插画、视频；
- 音乐、音效、字体；
- 从网站、社交媒体、素材库取得的参考；
- 需要进入最终交付而不只是内部观察的第三方素材。

纯粹由本项目已有设计 + Prompt 新生成的中间参考图，不需要为了形式再建立一份来源文件；但它仍然继承所使用参考素材的相关限制。

## 2. 记录在哪里

项目级限制写在 `VIDEO.md` 的“来源与限制”。

单个对象需要特殊说明时，可以在对应设计 / Prompt 文件顶部写简短来源，例如：

```text
来源：用户提供的人物参考图
用途：仅用于本项目角色一致性参考
```

或者：

```text
来源：品牌官网当前型号官方正面图
用途：产品结构与后期合成参考
```

不要求每个素材建立 sidecar、manifest 或数据库记录。

## 3. 用户提供素材

用户提供素材时，按用户明确的项目用途使用；不要自行扩大成“以后所有项目都可以复用”的公共素材。

用户如果说明不能上传外部服务、不能改图、只能内部使用或有其他限制，把该限制提升到 `VIDEO.md`，生成批次也必须遵守。

## 4. 网络与第三方素材

公开可访问不等于默认允许重新发布、改编或进入商业交付。

如果只是内部视觉参考，可以保留 URL / 来源并避免把第三方原图直接当作最终交付素材。

如果第三方素材本身要直接进入成片 / 广告交付，而当前权限不清楚，先标记阻塞项或要求用户提供可用版本，不静默假定有授权。

## 5. 真人参考

使用真人照片建立角色身份、声音或高相似度参考时，优先使用用户提供、项目授权或其他明确可用的来源。

不要为了“找一张差不多的脸”随意抓取无关真人照片，随后把它当成长期角色身份参考。

虚构角色如果只需要年龄、轮廓、服装或气质方向，可以用设计语言描述，不必默认绑定某个真实人物。

## 6. 品牌 / 产品素材

品牌官方素材主要承担：

- 产品事实；
- 工业结构；
- Logo / 型号；
- 后期合成。

公开宣传图可以作为当前产品真实性参考，但最终传播是否允许直接复用原图、Logo 或宣传文案，仍以项目 / 客户授权和当前交付要求为准。

## 7. 音乐、音效、字体

临时剪辑参考与最终交付分开。

临时音乐可以用于内部节奏验证，但最终成片使用的音乐、音效和字体应来自用户提供、项目已有许可、明确可用来源或当前交付允许的生成内容。

不要因为一首音乐“网上能播放”就默认可以进入对外交付。

## 8. 生成批次

`Bxxx` 只复制当前这一批 task 真正需要的参考素材，并继承这些素材的使用边界。同一参考被多个 task 使用时只复制一次。

如果某素材明确不能上传到外部模型，就不能因为“生成更方便”把它复制进批次。

## 9. 生成结果不会自动洗掉来源限制

一张第三方照片经过 AI 风格化、扩图或视频化，不代表原素材的来源 / 使用限制自动消失。

是否能进入最终交付仍需回到当前项目已知的来源与授权边界。

## 完成标准

真正影响生成和交付的外部素材都有足够来源信息；项目不会因为 Agent 的“默认可用”假设把未知授权素材静默变成正式成片资产。
