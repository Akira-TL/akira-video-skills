# 通用生图提示词规则

本文件定义 Akira Video 自己的长期图片提示词规则，不绑定具体图片生成模型。

## 1. 提示词来源

生图提示词必须从已经确认的设计和事实来源编译：

- 角色：`*_design.md`；
- 场景：场景设计 / 世界规则；
- 产品：官方产品事实与官方结构参考；
- 道具：当前长期结构说明；
- 视觉方向：项目已有视觉方向。

如果人物 / 地点 / 道具仍只有泛化功能描述，先在当前 `video-visual-design` 中完成具体设计。

## 2. 基础结构

按对象需要组织：

对象身份 / 类型
→ 稳定外形与结构
→ 当前状态
→ 服装 / 材质 / 颜色
→ 视角与构图
→ 背景
→ 光线
→ 画面类型 / 现实程度
→ 必要禁止项。

不是每个提示词都必须机械写满全部字段。

## 3. 身份参考图

人物身份 / 全身角色 / 状态参考的具体模板见 [`../character/CHARACTER-PROMPTS.md`](../character/CHARACTER-PROMPTS.md)。身份参考图优先：

- 中性表情；
- 容易辨认的姿态；
- 清楚的轮廓；
- 稳定的服装 / 材质；
- 简洁背景；
- 不加入剧情动作；
- 不加入只属于某个镜头的临时道具。

## 4. 场景参考图

环境 / 空场 / 空间结构参考的具体模板见 [`../environment/ENVIRONMENT-PROMPTS.md`](../environment/ENVIRONMENT-PROMPTS.md)。场景参考图优先稳定空间、材质、色彩和光线，不加入人物剧情动作。需要严格空间参考时使用场景四视图。

## 5. 产品 / 道具参考图

产品和结构性道具优先保持工业结构与部件数量。具体产品事实来自 `video-advertising` / 官方素材，生成提示词不能补造未知结构。

## 6. 严格四视图

当前对象需要四视图时，不自行改写模板结构：

1. 从已确认设计提取对象具体描述；
2. 把具体描述与 `FOUR-VIEW-PROMPTS.md` 对应模板组合；
3. 保留模板要求的 1:1、2×2、固定视角和禁止项；
4. 不把模型特定参数写进长期通用提示词；
5. 返回图先经 `video-review` 检查四格一致性。

## 7. 文字和 Logo

除非参考图本身的任务就是核验官方文字 / Logo，否则生成参考图尽量不依赖模型准确生成文字。

正式 Logo、型号、参数和长文本优先由官方文件或后期确定性合成。

## 8. 镜头专属生图

首帧、尾帧、分镜草图 / 关键帧如果只服务一个 Shot，其正式生图 Prompt 仍属于对应 Generation / Input Version；返回图若只服务当前 V 或 Shot，不自动提升到 `video/shared/`。这类输入从当前 Shot、资产设计和已采用参考版本编译，不临时重新设计人物或空间。

## 9. 正式提示词归属

正式送给模型的 Prompt 只保存在对应 Generation / Input Version，例如 `shared/G003/prompt_i01.md`；资产记录只引用来源，不复制相同正文。

同一 Generation 目标下 Prompt 或关键输入改变时建立新的 I；生成目标改变才新建 G。资产本身的文本设计继续由 Git 保存历史。

## 完成标准

提示词能从设计稳定地产生需要的参考图，而不是每次重新随机设计对象；模型换掉后，长期提示词的核心身份和结构仍然可复用。
