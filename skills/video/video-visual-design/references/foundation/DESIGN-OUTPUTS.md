# 角色与场景设计产物

本文件定义视觉设计如何转成长期复用素材。目标是用最少但足够的参考稳定后续视频，不要求每个项目生成完整“设定图套装”。

## 1. 角色基础身份

主要或重复出现的角色通常先形成：

- `CHR01.md` — 当前正式视觉设计、逻辑版本与当前采用来源；
- `Gxxx/prompt_iXX.md` — 真正执行的人物生图 Prompt；
- `Gxxx/takeNN.png` — 人物身份图、全身参考或四视图等实际生成结果。

Generated media 不复制成第二份 `CHR01_identity.png` / `CHR01_four-view.png` 资产文件；对象记录直接指向采用的 G/take。

简单远景人物、一次性群众角色或已经有可靠真人 / 官方角色素材时，不强制额外生成全部文件。

## 2. 服装不是新角色

同一人物换服装时继续保持同一个 `CHR01`。

例如：

- `CHR01_costume-a.png`；
- `CHR01_costume-b.png`。

新的服装参考必须继承相同：

- 脸；
- 发型；
- 年龄感；
- 身高 / 身体比例；
- 核心身份特征。

不要因为每套衣服单独生图，最后得到三个长得不一样的“CHR01”。

## 3. 表情参考按需生成

只有以下情况才值得额外建立表情参考：

- 角色有大量近景；
- 多个镜头需要重复同一特殊表情；
- 当前模型频繁把情绪变化变成身份变化；
- 角色有非常特殊的面部表现规则。

表情参考仍然基于同一个身份；不把一张夸张表情图替代基础身份图。

没有实际需要时不生成完整 expression sheet。

## 4. 身体 / 动作姿势

长期动作姿势只有多个镜头反复需要时才进入复用素材。

只属于一个镜头的姿势、动作路径或手势放在当前镜头 / 预演中，不进入公共人物素材。

## 5. 角色状态

剧情状态示例：

- normal；
- wet；
- damaged；
- dirty。

只有多个镜头确实需要这个状态，并且模型容易漂移时，才建立长期状态参考。

状态变化不改变角色 ID。

## 6. 场景基础设计

重复使用的重要地点通常形成：

- `LOC01.md` — 空间、材质、色彩、光线、逻辑版本与当前采用来源；
- `Gxxx/prompt_iXX.md` — 真正执行的环境生图 Prompt；
- `Gxxx/takeNN.png` — 空场环境、空间结构、四视图等实际生成结果；
- 可选布局图 / 预演图 — 非 Generation 来源时可直接保存在对象目录，并记录来源。

一次性背景、抽象背景或只出现一镜且空间关系不重要的地点，不强制建立完整场景参考。

## 7. 白天 / 夜晚不是新地点

同一空间结构没有改变，只是时间 / 天气 / 灯光状态变化时继续使用同一个 `LOC01`。

按需增加：

- `LOC01_day.png`；
- `LOC01_night.png`；
- `LOC01_rain.png`。

这些状态必须继承：

- 门窗；
- 墙体；
- 家具位置；
- 主要视觉锚点；
- 空间比例。

只有真正是另一个地点 / 空间结构时才创建新的 `LOCxx`。

## 8. 场景临时变化

只属于某个镜头的：

- 临时烟雾；
- 爆炸 / 破坏；
- 一次性灯光；
- 临时散落物；
- 摄影机位置；

默认留在 `SHOT.md` 或镜头专属图片，不污染长期场景设计。

如果某个变化在很多后续镜头持续存在，再升级为场景状态参考。

## 9. 道具与产品

虚构道具可以按角色 / 场景类似方式做结构设计和四视图。

真实产品不是“让 video-visual-design 自由设计”的对象：

- 结构来自官方事实 / 官方素材；
- `video-visual-design` 只能设计它如何进入画面和与整体视觉协调；
- 不能重新设计按钮、接口、比例、Logo 或型号。

## 10. 整体视觉方向

整片确实需要统一视觉语言时，优先直接写入当前 `Vxxx/VIDEO.md` 的整片表达方向；只有某份具体参考素材会被当前视频多个镜头复用时，才把该素材放入 `Vxxx/materials/` 并由正式记录引用。

没有跨镜头视觉约束的简单视频不必为此创建额外文件。

## 11. 最小原则

设计完成后先问：

“为了后续镜头稳定，我真正还缺哪一份参考？”

而不是：

“一个角色理论上还能生成哪些设定图？”

## 完成标准

长期素材足够稳定身份、结构和重复状态；一次性姿势 / 光效 / 动作没有被错误升级成公共资产；角色和地点不会因为换服装、表情或灯光就重新编号。
