# 人物角色生图提示词

这些模板用于把已经确认的人物设计编译成可复用的角色参考图。它们不重新设计角色；正式送去生成的正文仍写入对应 Generation / Input Version 的 `prompt_iXX.md`。

## 人物身份参考图

用于先稳定“这个人是谁”。

```text
生成 <CHRxx> 的人物身份参考图。

人物必须严格继承已确认设计：
- 年龄感：<...>
- 脸型与五官：<...>
- 发型：<...>
- 身高 / 身体比例：<...>
- 肤色：<...>
- 基础服装：<...>
- 稳定配件：<...>
- 关键颜色与材质：<...>

画面要求：
- 单人
- 中性表情
- 清楚可辨认的正面或轻微三分之二视角
- 上半身或头肩构图
- 简洁中性背景
- 均匀、不过度戏剧化的光线
- 不加入剧情动作
- 不加入临时道具
- 不改变服装、年龄、发型或身份特征

目标是建立后续镜头都可复用的人物身份基准，不追求剧情画面。
```

## 全身角色参考

用于稳定身高、比例、服装结构和配件位置。

```text
生成 <CHRxx> 的全身角色参考。

保持与身份参考完全相同的人物：
- 同一面部
- 同一发型
- 同一年龄感
- 同一身体比例
- 同一基础服装
- 同一配件位置
- 同一颜色与材质

构图：
- 头到脚完整可见
- 正常直立或自然中性站姿
- 手脚不得裁切
- 不做剧情动作
- 不做夸张透视
- 简洁背景
- 均匀光线

不要重新设计人物。
```

## 服装 / 状态参考

换装、湿身、受伤、污损等状态仍属于同一角色。Prompt 必须明确“身份不变，只改变当前状态”，并列出允许变化与禁止变化。

## 严格四视图

需要稳定正面、背面、全身比例与侧面结构时，直接组合已确认人物描述与 [`../assets/FOUR-VIEW-PROMPTS.md`](../assets/FOUR-VIEW-PROMPTS.md) 的人物严格四视图模板；不要另写自由多视角版本。

## 完成标准

人物 Prompt 能稳定身份、比例、服装和关键配件；剧情动作、一次性灯光和镜头临时状态没有混入长期人物参考。
