# 环境与场景生图提示词

这些模板用于把已经确认的地点 / 环境设计编译成稳定空间参考。正式 Prompt 只写入对应 Generation / Input Version。

## 空场环境参考图

用于先稳定“这个空间是什么”。

```text
生成 <LOCxx> 的空场环境参考图。

必须严格继承已确认的空间结构：
- 大体尺寸与比例：<...>
- 门：<数量 / 位置>
- 窗：<数量 / 位置>
- 主要通道：<...>
- 固定家具 / 建筑构件：<...>
- 关键视觉锚点：<...>
- 主要材质：<...>
- 主色与辅助色：<...>
- 基础主光来源与方向：<...>

画面要求：
- 不出现人物
- 不出现剧情动作
- 不随机增加家具、门窗或装饰
- 摄影机高度与透视自然
- 重点是空间结构可读，而不是戏剧化构图
- 固定物件位置必须与场景设计一致

目标是得到可被后续镜头反复引用的空间基准。
```

## 环境状态参考

白天 / 夜晚、雨天、停电、破损等如果空间结构不变，继续使用同一个 LOC ID。Prompt 明确列出不变的空间结构、允许变化的天气 / 灯光 / 表面状态，以及绝对不能移动或新增的门窗、墙体和主要家具。

## 空间结构参考

场景关系复杂时，优先生成能清楚看到门窗、主要家具、人物活动区和主摄影轴的广角结构参考，而不是漂亮但无法判断空间关系的氛围图。

## 严格四视图

需要前后左右空间一致性时，组合场景设计与 [`../assets/FOUR-VIEW-PROMPTS.md`](../assets/FOUR-VIEW-PROMPTS.md) 的场景严格四视图模板；四格必须是同一个三维空间，不允许用镜像替代反向观察。

## 完成标准

环境 Prompt 能稳定空间结构、材质、视觉锚点与主光方向；人物站位和单镜头动作没有污染长期环境参考。
