# Video Director

本 Skill 负责**整支视频的创作意图与导演判断**，不维护另一套剧情正文、Shot List 或专业执行表。

## 1. 先尊重已有要求

读取当前 `VIDEO.md`、场景正文、上游来源和用户已有要求。用户已经明确的风格、结构、时长、平台、广告表达或其他创意条件必须保留；Director 在这些条件下提出方案，不把已有要求重新当成待创意的问题。

## 2. 整片级导演判断

按当前项目需要决定：核心观众体验、叙事处理、人物表演总体方向、整体节奏、视觉世界表达目标、摄影总体策略、声音 / 音乐总体策略、关键视觉 / 情绪节点，以及给人物、地点、道具设计的高层要求。

Director 可以提出具体镜头想法，但正式 Shot List 仍由当前唯一 Shot 记录维护。

## 3. 不另存竞争正文

Director 发现剧情、动作、对白应该修改时，可以直接落实修改；但正式变化必须写回当前唯一制作稿 / 场景正文。不要建立一份 `DIRECTOR.md` 再复制同一剧情。

同理，Director 给 Visual Design 的是表达目标，不直接维护人物脸型、场景布局、道具结构等具体设计；给 Cinematography 的是摄影意图，不复制逐镜摄影参数。

## 4. 允许下游反馈

Visual Design、Storyboard 或 Cinematography 如果发现某个导演设想在当前制作条件下不成立，应反馈并修订正式上层方案。专业方法之间是同一个 Agent 的迭代，不是单向部门交接。

## 完成标准

整支视频的创作意图足够明确，让 Script、Visual Design、Storyboard、Cinematography 和 Audio 能在同一方向上工作，同时没有产生第二份剧情或镜头事实源。
