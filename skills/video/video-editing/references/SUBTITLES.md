# 字幕制作

当视频需要对白字幕、旁白字幕、无障碍字幕（Closed Captions, CC）或多语言字幕时使用。

字幕属于确定性后期，不让视频生成模型直接画精确字幕。

## 1. 字幕文本来自最终声音 / 最终脚本

字幕必须对应当前正式版本：

- 最终对白；
- 最终旁白；
- 已确认产品文案。

如果配音 / 旁白修改，字幕重新同步。

不要从旧脚本草稿复制字幕后一直沿用。

## 2. 普通字幕与无障碍字幕不同

### 普通字幕

主要呈现实际说话内容。

### 无障碍字幕（CC）

当前交付明确要求无障碍字幕时，按项目 / 平台规范增加必要信息，例如：

- 说话人；
- 重要环境声；
- 关键音效；
- 音乐信息。

不要把所有声音都机械写成 `[sound]`；只保留理解内容真正需要的信息。

## 3. 断句按语义，不按固定字符数

换行优先保留完整语义单元，例如：

- 主语 + 谓语；
- 动词 + 宾语；
- 固定短语；
- 人名 / 产品名；
- 数字 + 单位。

避免：

- 人名中间断行；
- 产品型号被拆开；
- 数字和单位分开；
- 介词 / 连词孤立在上一行；
- 一行只有一个标点或语气词。

不同语言字符宽度不同，不写一个全局字符上限；当前平台有明确规范时按该规范。

## 4. 显示时长

字幕应该有足够阅读时间，同时尽量与真实语音同步。

不写死一个全局每秒字符数；至少通过真实播放检查：

- 普通读者是否能读完；
- 极短字幕是否闪烁；
- 长字幕是否挡住多个镜头太久；
- 说话结束后字幕是否长时间残留。

当前平台 / 客户有阅读速度标准时按明确标准执行。

## 5. 入点与出点

字幕通常接近真实说话开始出现，并在对应内容结束后及时消失。

允许根据自然阅读：

- 略微提前；
- 略微延后；
- 一句话跨镜头继续。

但不要提前显示下一句导致观众先读到剧情信息。

## 6. 镜头切点

字幕可以跨切点，但要检查：

- 新镜头是否让字幕位置突然遮挡关键主体；
- 两条字幕是否在切点附近快速闪切；
- 画面已经切到另一个说话人时，上一句是否仍容易误解归属。

必要时调整时间 / 断句，不为了“字幕必须跟镜头一起切”破坏自然语义。

## 7. 多角色说话

需要区分说话人时，可以通过：

- 时间关系；
- 画面中当前说话人；
- 说话人标签（当前规范需要时）；

保持清楚。

普通剧情字幕不默认每句都加角色名。

## 8. 多语言

不同语言分别从该语言最终文本 / 音频生成字幕。

不要把源语言字幕逐行机器替换后假设时间轴一定适用。

目标语言句长变化时重新检查：

- 断句；
- 显示时长；
- 换行；
- 画面位置。

语言文件命名按 `akira-video` 的项目命名规则。

## 9. 烧录字幕与外挂字幕

### 外挂字幕

例如：

- SRT；
- WebVTT。

适合平台支持开关字幕、需要多语言或后续修改的情况。

### 烧录字幕

字幕直接进入画面。

适合：

- 平台 / 客户要求；
- 社交媒体默认静音场景；
- 设计本身需要字幕成为画面的一部分。

是否同时交付外挂 / 烧录版本由 `VIDEO.md` 交付要求决定。

## 10. 字幕文件格式

通用 Skill 不固定只使用 SRT / WebVTT / ASS 等某一种格式。

根据：

- 平台；
- 客户；
- 样式需求；
- 多语言；
- 无障碍要求；

选择。

没有样式需求时优先选择简单、广泛兼容、可编辑的格式。

## 11. 位置与安全区

默认字幕不要：

- 贴画面边缘；
- 遮挡主要人物嘴部 / 表情；
- 遮挡产品 / Logo / 关键操作；
- 落入平台 UI 高风险区域。

当前平台有官方安全区时按官方规范；没有时用实际画面检查，不写死一个通用像素值。

## 12. 多画幅

横版 / 竖版字幕位置必须分别看。

横版字幕安全不等于竖版安全。

如果同一个字幕文件不能携带版式信息，后期工程负责每个画幅的实际放置。

## 13. 样式

优先保证：

- 可读；
- 对比；
- 与品牌 / 整片视觉方向一致；
- 长句仍可用。

可以按项目使用：

- 纯文字；
- 描边；
- 阴影；
- 半透明底；
- 品牌化样式。

不要为了视觉设计让字重、动画或颜色降低可读性。

## 14. 动态字幕

逐字高亮、卡拉 OK、弹跳文字等只有当前视频风格真的需要时才使用。

短视频风格化字幕也要保证：

- 内容正确；
- 节奏与声音同步；
- 不遮挡关键主体；
- 不让每一个词都用不同动画造成视觉噪声。

## 15. 画面内已有文字

如果画面本身有：

- 产品 UI；
- 标题卡；
- 手机屏幕；
- 海报；

字幕不要无意义重复同一文本，除非无障碍 / 翻译要求需要。

画面内正式文字仍由图文后期或可靠官方素材控制。

## 16. 数字、单位、产品型号

字幕中的：

- 数值；
- 单位；
- 产品型号；
- 品牌名；

必须与当前已核验文本一致。

不要因为语音识别自动转写错误而改成另一个型号 / 数字。

## 17. 自动转写

自动转写可以作为初稿。

正式字幕必须人工 / Agent 对照最终声音复核：

- 漏词；
- 同音词；
- 人名；
- 专有名词；
- 数值；
- 标点；
- 分句。

不能把自动字幕直接当正式事实。

## 18. 版本

同一语言只有一个当前字幕版本时，直接更新正式字幕文件。

审片阶段确实要同时比较样式 / 文本时才保留临时版本。

不创建：

`subtitle_final2.srt`。

## 19. 最终 QC

完整播放检查：

- 每句文本正确；
- 无漏字幕；
- 无重复字幕；
- 时间同步；
- 阅读时长；
- 断句 / 换行；
- 人名 / 产品 / 数值；
- 安全区；
- 多画幅；
- 多语言是否串版；
- 是否残留占位文字 / 自动转写错误。

## 完成标准

字幕来自最终内容、按语义断句、时间可读、位置安全、语言版本正确，并由确定性后期控制，不依赖 AI 视频模型生成准确文字。
