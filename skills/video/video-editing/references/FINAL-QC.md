# 整片最终检查

仅在已有整片时间线或成片导出时读取。

## 1. 从头到尾看一次

最终 QC 必须基于真实成片。当前执行器能播放时先完整观看成片，不以逐镜头截图替代整体体验；如果只能看到截图、无法听声音或无法播放完整时间线，明确未验收维度，不宣称整片 QC 已完成。检查：

- 剧情 / 信息是否连续；
- 节奏是否存在明显死段；
- 镜头间动作、位置和视线是否跳变；
- 音乐、对白、环境声和音效是否互相遮挡；
- 字幕、标题、Logo 和产品型号是否可读；
- 画幅、分辨率、时长和平台要求是否满足 `VIDEO.md`。

## 2. 文字与品牌

精确字幕、Logo、型号、参数、价格或其他必须正确显示的文字，优先使用后期官方文件和可编辑文本，不依赖生成模型画字。

广告项目最终再核对：

- 功能和参数是否都来自已核验产品事实；
- 产品外观和结构是否与官方素材一致；
- 结尾落版没有增加未经证实的卖点。

## 3. 回到归属来源修问题

发现人物、产品、剧情或镜头本身错误时，回到对应脚本、复用素材或镜头修改，再重新进入后期。

不要在剪辑工程里用不可追踪的临时修补静默改写上游事实。

## 4. 最后一次因果检查

剧情视频最终至少再看一次“为什么这一镜接下一镜”，而不是只检查画面是否漂亮。视觉效果、音乐和转场不能掩盖故事本身已经断裂。
