# 成片统一处理

用于多个生成镜头进入同一成片后，处理跨镜头的色彩、曝光、稳定、噪声、清晰度、放大和其他确定性 finishing。

目标不是把所有镜头“磨成一样”，而是让它们在同一作品里看起来属于同一个摄影 / 美术系统。

## 1. 先区分生成错误和后期可修问题

适合后期统一处理：

- 白平衡轻微差异；
- 曝光 / 对比度差异；
- 饱和度差异；
- 轻微颗粒 / 噪声；
- 小幅稳定；
- 合理的锐化 / 降噪；
- 当前交付需要的放大；
- 小幅速度调整；
- 可控的局部遮罩 / 合成。

不应仅靠 finishing 掩盖：

- 人物身份错误；
- 产品结构 / 型号错误；
- 关键动作错误；
- 大幅空间关系错误；
- 严重肢体 / 几何问题；
- 生成视频内部不可修的时序断裂。

这些回 `video-review` 决定重生成或重写上游。

## 2. 色彩统一

跨模型、跨批次生成常见差异：

- 色温；
- 曝光；
- 黑位；
- 对比度；
- 饱和度；
- 高光；
- 肤色；
- 产品颜色。

统一时优先对齐：

1. 正确曝光和白平衡；
2. 人物肤色 / 身份可读性；
3. 产品真实颜色（广告时）；
4. 整片视觉方向；
5. 风格化 finishing。

不要为了统一“电影 LUT”让真实产品颜色失真。

## 3. 光线差异

相邻镜头的主光方向如果在设计上本来一致，但生成结果只是亮度 / 色温有轻微不同，可以后期调整。

如果主光方向、阴影结构或时间状态完全相反，通常是镜头 / 场景连续性问题，不是简单调色问题。

## 4. 稳定

后期稳定适合：

- 模型产生的小幅意外抖动；
- 本应稳定的机位轻微漂移；
- 手持镜头中不受控的高频抖动。

如果稳定需要大幅裁切、产生明显变形或破坏产品 / 人物结构，优先重新生成或重新设计。

## 5. 降噪、锐化和放大

生成源分辨率低于交付分辨率时，可以使用后期放大。

放大不是恢复真实不存在的结构细节。检查：

- 人脸是否被重新“美化”成另一个人；
- 产品文字 / Logo 是否产生伪细节；
- 细线和边缘是否过锐；
- 皮肤 / 布料是否变塑料；
- 噪声和压缩是否被过度放大。

如果放大模型改变了身份 / 产品结构，不接受为“清晰度提升”。

## 6. 帧率与速度

当前交付有明确帧率要求时，在最终后期统一。

不要用简单改 FPS 的方式偷偷改变镜头实际播放速度。

需要慢动作 / 变速时检查：

- 动作是否仍自然；
- 插帧是否产生肢体 / 产品结构伪影；
- 对白 / 声音是否需要单独处理。

## 7. 颗粒与质感

统一颗粒、轻微锐度和质感可以帮助跨模型镜头看起来属于同一片。

但风格层不能覆盖：

- 关键结构错误；
- 不同世界本来应该存在的差异；
- 产品官方颜色 / Logo。

## 8. 跨世界项目

多个视觉世界本来就可以有不同 finishing。

统一的是各自世界内部规则，而不是把所有世界调成一个色调。

跨世界保持项仍以 `video-design` 的世界规则为准。

## 9. 派生媒体

如果 finishing 只存在于 Premiere Pro / Resolve / After Effects 工程里，不需要额外导出每个“调色版镜头”。

只有跨软件复用、长期中间母版或当前后期流程确实需要烘焙时，才在 `video/edit/` 保存用途明确的派生文件。

原始 `takeNN.mp4` 不覆盖。

## 10. 最终检查

统一处理后至少看：

- 相邻镜头是否有突兀曝光 / 色温跳变；
- 主角色肤色 / 身份是否稳定；
- 产品颜色是否正确；
- 锐化 / 降噪是否产生新伪影；
- 放大是否改写细节；
- 画幅 / 裁切是否仍符合交付。

## 完成标准

不同模型 / 批次的镜头在同一作品中具有统一 finishing，同时没有用调色、稳定、放大或锐化掩盖真正的身份 / 结构 / 连续性错误。
