# 字幕、Logo、标题与片尾图文

用于所有必须准确显示文字、品牌图形或最终片尾信息的后期工作。

## 1. 精确文字默认后期完成

以下内容默认不依赖视频生成模型直接画：

- 字幕；
- 标题；
- Logo；
- 产品型号；
- 参数；
- 价格；
- 网址 / 二维码；
- 品牌主文案；
- 片尾主卡。

优先使用：

- 可编辑文本；
- 官方 Logo / 品牌文件；
- 客户提供的正式字体 / 规范；
- 当前项目已有图形素材。

## 2. 字幕

字幕的文本来源、语义断句、显示时长、外挂 / 烧录、无障碍、多语言和完整 QC 统一按 [`SUBTITLES.md`](SUBTITLES.md)。这里仅保留图文层原则：字幕要可读、与整片视觉一致，并且不能遮挡脸、产品或关键动作。

## 3. 标题与说明文字

标题只保留当前视频真正需要的信息。

不要因为后期可以写字，就把镜头本可以自己表达的剧情再用标题解释一遍。

说明性文字较多时，优先把它当明确的信息设计，而不是散落在多个镜头里的随机贴字。

## 4. Logo

真实品牌 Logo：

- 使用官方文件；
- 不让生成模型重画；
- 不改变比例、字形或品牌色，除非品牌规范明确允许；
- 不因为构图方便随意拉伸或透视变形。

如果 Logo 需要进入三维场景或产品表面，优先使用后期跟踪 / 合成，而不是让模型自行生成一个“相似 Logo”。

## 5. 产品型号、参数与价格

所有型号、参数和价格必须回到当前已核验来源。

生成视频中偶然出现的文字不能作为事实来源。

价格只有当前 brief / 客户 / 官方交付明确要求且仍有效时才进入成片。

## 6. 片尾主卡

品牌 / 产品项目默认保持简洁：

- 品牌；
- 产品名 / 型号；
- 一句主信息；
- 最多 1–2 个已证实卖点（确实需要时）；
- 必要的行动信息。

不默认堆入全部产品功能、参数和剧情主题总结。

## 7. 安全区与多画幅

字幕、Logo、标题和片尾图文必须考虑当前交付画幅和平台 UI 遮挡。

如果当前平台 / 客户给出了官方安全区，按当前规范执行。

没有明确平台规范时：

- 避免贴边；
- 主要图文保持在容易适配的中心区域；
- 横版转竖版时重新检查文本位置；
- 不写死一个通用像素安全区。

## 8. 可读性

至少检查：

- 字体大小；
- 对比度；
- 背景复杂度；
- 出现时长；
- 动画速度；
- 多语言文本长度。

一张主卡看起来很漂亮，但观众来不及读完，仍然是不合格。

## 9. 图文动画

动画应服务：

- 信息层级；
- 品牌语气；
- 与画面 / 音乐节奏连接。

不要为了“动效感”让文字一直漂移、缩放、旋转导致可读性下降。

## 10. 最终检查

导出前逐项核对：

- 正确文本；
- 官方 Logo；
- 产品型号 / 参数；
- 字幕时序；
- 多画幅位置；
- 片尾出现时间；
- 是否存在拼写错误、占位文字或生成乱码。

## 完成标准

所有必须精确的文字 / 品牌图形由确定性后期控制，观众能在当前画幅和节奏下正确读到真正需要的信息。
