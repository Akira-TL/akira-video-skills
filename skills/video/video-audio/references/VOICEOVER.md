# 旁白与画外音

当视频使用叙述者、角色内心画外音、品牌旁白或说明性 Voice-over 时使用。

## 1. 先区分旁白与角色对白

角色对白发生在当前场景 / 行动关系中。

旁白 / 画外音可以来自：

- 外部叙述者；
- 角色回忆 / 内心；
- 品牌 / 信息说明；
- 不在画面内的角色声音。

旁白文本仍属于 `video-script`；本 Skill 只负责声音身份、语速、表演、生成和后期关系。

## 2. 旁白不是剧情补丁

优先让画面和人物行动自己说明：

- 发生了什么；
- 谁在做什么；
- 产品怎样使用；
- 角色怎样选择。

不要因为脚本 / 镜头不清楚，就加一句旁白把所有内容解释出来。

旁白真正适合：

- 压缩长时间 / 背景；
- 表达当前风格明确允许的内心视角；
- 提供画面本身无法自然呈现的必要信息；
- 品牌 / 纪录 / 教程类作品的结构信息。

## 3. 画面不要逐字重复旁白

旁白说：

“我第一次意识到这座城市已经变了。”

画面不一定需要再出现文字“城市变了”或角色直接做一个明显“意识到”的动作。

更好的关系通常是：

- 旁白给抽象 / 时间 / 主观信息；
- 画面给具体行动 / 证据 / 情绪。

两者可以互补。

## 4. 小说改编

小说原文旁白不能机械复制成视频旁白。

先判断：

- 这段信息能否视觉化；
- 是否真的需要保留；
- 视频角色会不会自然说出来；
- 旁白是否符合当前叙述视角。

保留旁白时也要改写成适合**说出来**的句子，而不是书面段落。

## 5. 旁白脚本

旁白文本可以在 `SCRIPT.md` 中标记，例如：

```markdown
旁白（CHR01）：我以为问题只是这一件衬衫。
```

或者：

```markdown
旁白（Narrator）：城市还没有醒。
```

不需要为了旁白单独创建新的脚本层目录。

## 6. 旁白声音身份

如果旁白是现有角色：

- 基础音色与该角色正常对白保持一致；
- 可以因为叙述时间 / 心理距离改变语速、空间感和情绪；
- 不随机换成另一个声音。

如果是独立 Narrator：

只有需要跨多个段落 / 视频保持统一时，才建立长期声音定义。

## 7. 临时旁白

Animatic / 粗剪可以使用：

- Agent 临时朗读；
- 占位 TTS；
- 用户临时录音。

目的只是验证：

- 时长；
- 停顿；
- 镜头是否放得下；
- 旁白是否与画面重复。

临时旁白不能因为已经剪进工程就自动变成最终声音。

## 8. 自然时长

旁白和对白一样，需要真实朗读检查。

考虑：

- 语速；
- 情绪；
- 句间停顿；
- 呼吸；
- 画面需要的空白。

不要靠强行加速语音把过长旁白塞进短片。

如果旁白太长，优先：

- 精简文字；
- 去掉画面已经说明的信息；
- 分散到不同段落；
- 调整镜头 / 总时长。

## 9. 旁白与镜头

旁白不需要人物正面口型时，可以：

- 跨多个镜头；
- 提前进入下一镜；
- 延续到下一镜；
- 配合蒙太奇。

因此不要为了每一句旁白都生成一个“人在说话”的镜头。

## 10. 生成与归档

需要外部 AI / TTS 生成旁白时，由 `video-generation` 建声音生成包。

候选暂存在 `.tmp/.../returns/`，例如：

`voiceover_take01.wav`
`voiceover_take02.wav`

最终整片旁白通常归档为：

`video/edit/voiceover.wav`

如果旁白属于某个角色且要长期跨项目 / 多段复用，基础声音参考仍放 `video/materials/voices/`。

## 11. 修改脚本后重新生成

正式旁白文本变化后：

- 旧音频不再自动有效；
- 字幕同步更新；
- 时间线重新检查；
- 依赖旁白节奏的镜头长度重新回测。

不要只改字幕而继续播放旧旁白。

## 12. 广告 / 产品旁白

产品功能、参数和宣传表达仍受 `video-advertising` 的产品事实约束。

旁白不能为了语句顺畅：

- 添加不存在的功能；
- 把“帮助”说成“保证”；
- 编造速度 / 温度 / 距离 / 自动化能力。

最终文字必须能回到已核验来源。

## 13. 旁白与音乐

有旁白时音乐优先让出：

- 频段；
- 节拍密度；
- 音量；
- 注意力。

不写死通用 dB / LUFS；最终按实际混音和交付标准处理。

## 14. 字幕

旁白字幕从**最终确认的旁白文本 / 音频**生成，不从旧脚本草稿复制。

字幕仍由 `video-editing` 确定性完成。

## 15. 审片

听完整旁白并检查：

- 文本是否正确；
- 声音身份；
- 语速 / 停顿；
- 情绪；
- 是否重复画面已经显然表达的信息；
- 是否抢过人物表演；
- 是否遮挡音乐 / 关键音效；
- 产品 / 品牌事实是否准确。

## 完成标准

旁白提供真正必要的叙述价值，文本适合口语表达，声音身份稳定，时长与画面匹配；它不会成为修补不清楚脚本或镜头的万能解释层。
