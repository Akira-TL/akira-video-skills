# 音乐与配乐设计

当视频需要背景音乐、角色 / 品牌主题动机、转场音乐、生成配乐或临时节奏参考时使用。

音乐属于整片声音设计；最终选中音乐、旁白和主混音放在 `video/edit/`，不建立新的一级 `music/` / `audio/` 目录。

## 1. 先区分临时音乐与最终音乐

### 临时音乐

用于：

- 动态分镜（Animatic）验证节奏；
- 粗剪情绪；
- 测试转折和停顿；
- 向用户说明音乐方向。

临时音乐不是默认交付素材。

如果来源 / 授权不适合正式交付，文件名或后期说明明确标记为：

`temp-music.wav`

不要在最后导出时忘记替换。

### 最终音乐

必须满足当前项目的：

- 使用权限；
- 风格；
- 时长；
- 剪辑结构；
- 对白可懂度；
- 平台 / 客户要求。

## 2. 音乐先服务结构

先判断音乐在当前视频里做什么：

- 建立世界 / 时间；
- 支撑人物情绪；
- 推动节奏；
- 强化转折；
- 给产品 / 品牌建立动机；
- 连接蒙太奇；
- 在结尾完成回收。

不要只因为“视频应该有 BGM”就从头铺到尾。

## 3. Cue（音乐段落）

音乐 cue 可以围绕故事段落安排，例如：

```text
00:00–00:08 低强度建立
00:08–00:22 冲突增加
00:22–00:30 突然收掉低频，给角色决定留空间
00:30–00:42 解决段主题回归
00:42–00:48 品牌落版尾音
```

这是编辑规划，不要求严格逐帧锁定。

简单短片只有一段音乐时不需要单独维护 cue 文件。

## 4. 音乐不要绑架对白和表演

对白 / 重要表演需要自然停顿时：

- 音乐可以降强度；
- 让出频段；
- 减少节拍密度；
- 暂停；
- 让声音桥接代替强卡点。

不要为了卡节拍：

- 剪掉必要反应；
- 让角色加速说话；
- 把产品操作剪得看不清；
- 强迫每个镜头在拍点上切。

## 5. 音乐主题与动机

长一点的剧情 / 品牌视频可以设计少量重复动机，例如：

- 角色主题；
- 产品 / 品牌主题；
- 世界主题；
- 冲突动机。

动机可以通过：

- 旋律；
- 节奏；
- 音色；
- 和声；
- 某个声音标识；

重复出现。

不要为每个角色和场景都创建主题，导致整片音乐碎片化。

## 6. 多世界音乐

不同世界可以改变：

- 乐器；
- 质感；
- 空间感；
- 节奏；
- 和声。

但如果观众需要知道“仍然是同一角色 / 同一主题”，可以保留：

- 同一旋律轮廓；
- 同一节奏动机；
- 同一声音标识。

音乐变化与 `video-design` 的世界规则保持一致。

## 7. 转场与音乐

音乐可以帮助：

- 提前进入下一段；
- 延续上一段；
- 用停顿制造转折；
- 用音色 / 节奏匹配连接两个世界。

不要求画面和音乐每次同时切换。

## 8. 音乐生成

需要外部 AI 生成音乐时，由 `video-generation` 整理一次性生成包。

任务文件至少写：

- 用途；
- 目标时长；
- 情绪 / 节奏；
- 结构段落；
- 是否需要无缝循环；
- 是否需要结尾收束；
- 是否需要 stems / 分轨（只有当前后期真的会用）；
- 返回文件名。

多个候选先放 `.tmp/.../returns/`，例如：

`music_take01.wav`
`music_take02.wav`

选中后正式进入：

`video/edit/music.wav`

或描述性用途名。

## 9. 不默认要求分轨

简单短片只需要一个完整音乐文件时，不要求 stems。

以下情况才值得要分轨：

- 需要对白 ducking 的更精细控制；
- 要在不同段落保留 / 去掉鼓；
- 多语言版本要调整音乐 / 人声；
- 客户明确要求；
- 后期需要重构音乐。

## 10. 音乐与声音层次

音乐进入混音后要给：

- 对白；
- 旁白；
- 关键产品操作音；
- 关键剧情音效；

让出必要空间。

通用 Skill 不写死一个 LUFS / dB 数值；有平台 / 客户响度标准时按明确交付要求执行。

## 11. 生成音乐的时长

最终音乐时长可以：

- 直接匹配成片；
- 生成更长后剪辑；
- 分段生成后后期拼接。

如果音乐需要无缝 loop，生成时明确结构 / 尾部；如果结尾要落版收束，不能只给一个无限循环没有结束。

## 12. 音乐版本

普通修改由后期工程 / 正式音乐文件管理。

只有需要同时比较多个音乐方向时，候选才临时编号。

选定后不长期堆：

`music_final2.wav`
`music_really_final.wav`。

## 13. 来源与授权

第三方 / 素材库音乐按 `video-materials/references/SOURCE-RIGHTS.md` 记录必要来源与使用边界。

网上能播放不等于允许进入最终对外交付。

## 14. 审片

音乐加入粗剪后从头看：

- 是否遮挡对白；
- 情绪是否提前“告诉观众答案”；
- 转折是否仍有空间；
- 音乐高潮是否和真正剧情高潮对齐；
- 产品信息是否能被听 / 看清；
- 结尾是否有自然收束；
- 音乐是否掩盖节奏问题。

如果关掉音乐后剧情完全不成立，先检查脚本 / 剪辑，而不是继续加更强音乐。

## 完成标准

音乐服务故事、表演、产品和剪辑结构；临时与正式音乐明确分开，最终文件具有可交付来源，音乐不会为了卡点破坏人物与信息节奏。
