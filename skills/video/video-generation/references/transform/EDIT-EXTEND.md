# 视频延长与生成式编辑

当已有视频基本正确，需要延长连续镜头、局部生成式修改、Video-to-Video（V2V）编辑或生成式替换时使用。

具体模型支持哪些 edit / extend operation 由模型适配器或当前官方资料核验；本文件只规定项目语义和资产边界。

## 1. 先判断为什么不直接后期

以下问题优先确定性后期：

- 裁切；
- 变速；
- 字幕；
- Logo；
- 图文；
- 调色；
- 音量；
- 替换配音；
- 简单遮罩 / 合成；
- 画幅适配。

只有需要模型**重新生成画面内容**时才考虑 V2V / edit / extend。

## 2. 延长同一个 Shot

以下情况通常仍属于同一个 Shot：

- 摄影机连续不切；
- 同一主体 / 场景；
- 动作继续发生；
- 只是需要更多时间完成当前镜头目的；
- 没有新的独立观察点。

例如：

`CHR01 抬起产品 → 停顿 → 看向结果`

原生成只完成到“抬起产品”，可以延长继续完成停顿和反应。

## 3. 什么时候不是延长，而是新 Shot

出现以下变化通常建立新的 Shot：

- 明显硬切；
- 新摄影机位置 / 角度；
- 从人物切产品特写；
- 新反应镜头；
- 新场景；
- 新叙事功能。

不要因为一个模型支持“extend”就把本来需要剪切的多个镜头强行做成一个长镜头。

## 4. 延长从实际出口开始

延长当前采用结果时，起点来自**真实视频末尾可见状态**：

- 人物位置；
- 朝向；
- 手持物；
- 产品状态；
- 摄影机位置 / 运动；
- 光线；
- 当前动作阶段。

不从原计划出口重新想象。

## 5. 延长提示词只写“接下来”

延长提示词优先描述：

- 从当前尾帧继续什么动作；
- 摄影机怎样继续；
- 哪些身份 / 结构必须保持；
- 希望结束在哪里。

不要把已经完成的动作完整重写一遍，否则模型可能重复动作。

## 6. 首尾 / 关键参考

模型支持尾帧 / continuation reference 时，优先使用当前采用视频的真实尾帧，而不是重新生成一张“相似尾帧”。

如果必须生一个目标尾帧，它仍按 `PREVIS.md` 从当前镜头计划派生并先验收。

## 7. V2V 局部修改

适合：

- 改一个局部对象；
- 调整环境状态；
- 替换不正确背景元素；
- 对生成视频做受控视觉修改；
- 当前模型支持的局部 edit。

前提是原视频的核心：

- 人物身份；
- 产品结构；
- 动作；
- 摄影；

大体已经正确。

如果整个镜头都错，直接重生成通常比层层补丁更清楚。

## 8. 生成式编辑不是“无损修改”

即使只要求改背景，模型也可能影响：

- 人脸；
- 手；
- 服装；
- 产品；
- 纹理；
- 摄影稳定性。

所以 V2V 编辑后的结果必须重新看**完整视频**，不能只检查被修改区域。

## 9. 风格转换

生成式风格转换可能改变：

- 人物身份；
- 材质；
- 产品工业结构；
- 场景空间；
- 文字 / Logo。

如果项目需要稳定人物 / 产品，风格转换后按完整身份 / 产品 / 空间 QA 重新验收。

风格变化很大且会影响整片时，先回 `video-design` 更新正式视觉方向，不把新风格偷偷藏在某个 Shot edit 里。

## 10. 原始生成结果永远保留

假设：

`take03.mp4` 是当前输入。

AI 编辑 / 延长输出如果形成一个完整可用镜头，使用下一个未占用编号：

`take04.mp4`

原 `take03.mp4` 不覆盖。

如果 `take04` 被采用，在 `SHOT.md` 记录：

- 来源 take03；
- 对应 edit / extension 提示词；
- 模型 / 使用入口（必要时）；
- 新的实际出口。

## 11. 平台只返回“延长片段”时

如果工具只返回新增尾部片段，而不是完整延长视频：

1. 原始 `takeNN` 保持不动；
2. 延长片段先留一次性生成包 `returns/`；
3. 审片确认身份 / 动作 / 摄影可连续；
4. 在 `video/edit/` 用确定性剪辑拼接；
5. 只有项目确实需要长期保存该片段为独立中间媒体时，才给它用途明确的名称。

不要把一个只包含后半段的文件误命名为完整 `take04.mp4`。

## 12. 编辑后的连续性

采用生成式编辑 / 延长结果后，重新记录实际出口。

如果修改影响：

- 人物位置；
- 产品状态；
- 光线；
- 动作方向；
- 时长；

重新检查依赖此 Shot 的下游镜头。

## 13. 产品修改边界

真实产品：

- 可以修掉模型生成的错误背景；
- 可以做官方素材合成；
- 可以在官方依据内保持结构。

但不要用生成式编辑：

- “修”出一个官方没有的接口；
- 改型号；
- 添加新功能；
- 自由重设计产品。

产品错误优先回官方结构参考 / 重生成。

## 14. 人物修改边界

人物身份错时，局部修脸只有在当前工具真的能稳定保持完整时空一致性时才考虑。

如果修脸会：

- 逐帧抖动；
- 表情丢失；
- 变成另一个人；

优先重生成镜头。

## 15. 编辑提示词版本

生成式编辑 / 延长提示词可以和主提示词同处镜头目录，例如：

`prompt_v02.md` — 原完整生成
`edit_v01.md` — 局部生成式编辑
`extend_v01.md` — 延长

只有同时存在并对复现有意义时才保留这些文件；一次性尝试且未采用的编辑提示词可以随生成包清理。

## 16. 迭代顺序

一次只做一个主要生成式修改。

例如先：

- 修背景；

验收后再决定是否：

- 延长。

不要在一次 edit 中同时要求换背景、改服装、重做产品、延长时长和改变摄影。

## 17. 模型能力不匹配

如果当前模型的 edit / extend 会严重损伤身份或结构：

- 换模型 / 模式；
- 回到原参考重生成；
- 使用确定性后期；

而不是为了利用某个功能强行接受更差结果。

## 完成标准

延长和生成式编辑只在真正需要重新生成画面时使用；同一 Shot 的生成编辑结果可追溯且不覆盖原始媒体，新的实际出口重新进入连续性，硬错误不会被层层生成补丁掩盖。
