# 视频延长与生成式编辑

当已有 Take 基本正确，但确实需要模型重新生成画面内容来延长、局部修改或 Video-to-Video 编辑时使用。具体 edit / extend 能力按当前官方资料核验。

## 1. 先判断是否应该后期

裁切、变速、字幕、Logo、图文、调色、音量、配音替换、简单遮罩 / 合成和画幅适配优先确定性后期。只有需要重新生成像素内容时才建 edit / extend Generation 输入。

## 2. Generation 关系

如果制作目标仍是同一个 G，只是基于已有 Take 调整 Prompt / reference / edit 模式，可以建立新的 I，并明确该 I 的 source Take。若叙事目标、观察点或任务功能已经改变，建立新的 G。

同一最终 Shot 可以由多个 G / Take 拼接；不要因为平台叫“extend”就强行把本应切镜的内容当成同一个生成任务。

## 3. 从真实出口继续

延长时以 source Take 的真实末尾状态为起点：人物位置 / 朝向、手持物、产品状态、摄影机位置与运动、光线和动作阶段。不要从原计划出口重新想象。

Prompt 只写接下来需要发生的动作、摄影和必须保持的身份 / 结构，不重复已经完成的动作。

## 4. 原始 Take 不覆盖

任何 edit / extend 返回都是新的 Take，原 source Take 永远保留。新 Take 继续使用当前 G 的下一个编号；如果新建了 G，则在新 G 内从自己的 `take01` 开始。

Generation 记录 source Take 和实际 I，但不写 selected。最终用了原 Take、新 Take、哪段时间或二者拼接，以资产 / Shot 临时记录或正式剪辑记录为准。

## 5. 局部编辑仍要完整 Review

即使只要求改背景，模型也可能改变人脸、手、服装、产品、纹理或摄影稳定性。返回后必须重新检查整个候选及受影响的连续性，不只看修改区域。

风格变化影响整片时先回 `video-visual-design` 修改正式视觉方向；产品结构变化受 `video-advertising` 的事实边界约束。

## 6. 平台只返回新增尾段

新增尾段本身仍是一个可独立 Review 的 Take / 候选结果。通过 Review 后，若最终需要与 source Take 连成一个 Shot，在 `Vxxx/edit/` 用确定性剪辑拼接；不要把只含后半段的文件伪装成完整镜头。

## 7. 一次改一个主要变量

优先一次只改变背景、延长动作、局部对象等一个主要生成变量；持续失败时回查参考资产、Shot / Cinematography、Prompt 或当前模型是否适合，而不是层层补丁。

## 完成标准

生成式编辑 / 延长有清楚的 source Take、G/I 和新 Take；原始媒体不覆盖，实际采用关系仍由消费方维护。
