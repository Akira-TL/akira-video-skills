# 一次性 Generation Pack

Generation Pack 是给用户拿到外部 AI 平台执行的一次性派生包。它只从正式项目内容复制 / 编译，不成为长期事实源。

所有包直接放在当前项目 ForgeRelay 工作区内的 `.tmp/`，不要写到操作系统其他临时目录。

## 1. 图片生成包

用于角色、场景、道具、产品等长期参考素材，也可以用于某个 Shot 专属的首帧、尾帧、Storyboard / Keyframe 生图。长期素材返回 `video/materials/`；Shot 专属图片返回对应 Shot。

推荐最小结构：

```text
.tmp/<pack-name>/
├── README.md
├── <object-id>.md
└── materials/        # 只有确实需要输入参考时创建
```

README 写清：

- 本次要生成什么；
- 建议生成顺序；
- 每个对象的返回文件名；如果预计一次会生成多个候选，同时约定 `*_take01.png`、`*_take02.png`；
- 是否使用严格四视图；
- 需要人工重点检查什么。

对象 Prompt 文件可以直接包含设计来源、当前长期 Prompt、四视图模板（如果使用）、参考图列表和返回文件名。

图片只返回一个确定结果时可以使用对应长期文件名；一次返回多个候选时先使用 `<长期名去扩展名>_take01.png`、`_take02.png` 等候选名，避免同名覆盖。

不要把整个项目资料复制进包。

## 2. 视频生成包

用于一个或一组 Shot。

推荐结构：

```text
.tmp/<pack-name>/
├── README.md
├── SC01_SH010.md
├── SC01_SH020.md
└── materials/
```

每个 Shot 文件至少写清：

- Shot ID；
- 目标时长；
- 当前使用的 Prompt；
- 参考素材及各自职责；
- 用户需要在生成界面确认的参数；
- Hard Constraints；
- 返回文件名。

返回文件名在对应 Shot 目录内使用 `takeNN.mp4`。打包前先查看该 Shot 已有 Take，预留下一组未使用编号；不得因为新 Prompt / 新模型重新从 `take01` 开始覆盖旧结果。

如果用户需要从包外单独传回文件，为避免丢失归属，可以使用 `SC01_SH010_take01.mp4`；导回 Shot 后再按项目现有简洁命名整理。

## 3. Prompt 来源

包里的 Prompt 不能成为唯一版本。

长期图片 Prompt 必须已存在于 `video/materials/`；长期 Shot Prompt 必须已存在于对应 `video/shots/<shot-id>/`。

包里只复制当前版本，并根据具体模型适配器做必要的外部执行说明。

## 4. 参考素材

只复制最小充分参考集，并说明每份素材负责什么：人物身份、服装、场景、产品结构、动作、摄影、风格或声音。

不把完整 `video/materials/` 目录整体复制出去。

## 5. 对外交付

Generation Pack 只有少量文本时可以直接给目录；包含多张参考图、多个 Shot 或用户明确需要单文件交付时，可以把当前 pack 压成一个 zip。

zip 仍保存在同一个项目 `.tmp/` 中，例如：

`.tmp/SC01-generation-pack.zip`

不要为了压缩包把内容复制到系统其他临时目录。zip 与 pack 都是一次性派生物。

## 6. 用户生成后导回

一批返回文件需要先暂存时，放在当前 pack 内的 `returns/`，例如：

```text
.tmp/SC01-generation-pack/
└── returns/
    ├── SC01_SH010_take01.mp4
    └── SC01_SH020_take01.mp4
```

然后：

1. 根据返回文件名确定归属；文件名不规范但有明确一一对应关系时可以整理，多个返回文件无法可靠对应对象 / Shot 时停止并向用户确认，不按上传顺序猜；
2. 保留原始返回文件，先进入 `video-review`；
3. 图片有多个候选时先完成选择，只有选中的结果归档为对应长期稳定名；未选候选默认留在临时 pack 等待清理；
4. 图片长期素材归入对应 `video/materials/<category>/`；
5. Shot 视频、镜头专属图片 / 音频归入对应 Shot；
6. 如果文件名不符合约定但归属明确，正式归档时整理为项目命名；
7. 更新必要的 `VIDEO.md` 当前工作。

返回文件也不能因为“暂存在 pack”就成为长期唯一副本。

## 7. 删除临时包

只有当返回结果已经进入正式项目、包里没有唯一 Prompt / 唯一参考图、且没有尚未导回的生成结果时，才删除整个 Generation Pack。

Generation Pack 默认不进入 Git。

## 完成标准

用户打开包即可知道按什么顺序生成、每个 Prompt 对应什么、要上传哪些素材、生成后文件叫什么；同时删除整个包不会损失任何长期项目信息。
