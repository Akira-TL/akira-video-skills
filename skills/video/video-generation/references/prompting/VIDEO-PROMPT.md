# 通用视频提示词编译

正式视频 Prompt 属于某个 Generation 的 Input Version，例如 `V001/G003 I02`；Prompt 正文只保存在该 I 的 Prompt 文件中，不在 Shot 或资产记录复制第二份。

## 1. 从正式意图编译

开始前确认当前 Generation 目标、相关 Shot / 场景、实际采用的参考资产版本和必要声音要求已经明确。缺失镜头叙事意图时回到 `video-storyboard`；缺失机位 / 构图 / 运动时回到 `video-cinematography`；缺失身份 / 场景 / 道具参考时回到 `video-visual-design`。

## 2. 通用结构

按当前任务需要组织：主体 / 起始状态 → 动作 → 摄影 → 环境变化 → 表演 → 秒级时序 → 对白 / 声音（适用时）→ 必要一致性与限制。不是每个任务都机械写满。

图生视频时，参考图已经清楚表达的静态身份、服装、构图和场景不必长篇重复；重点描述接下来发生什么。

## 3. 当前模型能力

具体模型的输入类型、参考数量、时长、分辨率、声音、首尾帧、edit / extend 等能力在真正执行当前 I 时查看当前官方资料。没有可靠依据的能力保持未确认，不用历史记忆补齐，也不需要安装供应商 Adapter Skill。

模型限制不能反向偷改剧情、资产事实或 Shot 核心目的。如果当前模型明显不适合，可以换模型 / 模式；若必须改变创作目标才能实现，则回到正式制作记录修改，而不是把变化藏进 Prompt。

## 4. 时间与复杂度

动作数量必须和目标时长相容。优先自然秒级顺序，不把后期才能精确完成的剪切点、字幕、Logo、音量等写成生成硬约束。

## 5. 多镜头 Generation

一个 G 可以计划覆盖多个 Shot，也可以让模型内部 hard cut。Generation 记录计划覆盖范围；模型返回后，真正形成了哪些可用镜头、各自采用哪段 Take，由后续 Review 与 Shot / 剪辑记录确定。

## 6. 迭代

失败后先判断问题来自参考资产、Shot / 摄影设计、Prompt 表达、模型能力还是随机执行。目标不变时修改正式输入产生新的 I；目标改变才新建 G。一次迭代优先改变一个主要变量。

## 完成标准

当前 I 的 Prompt 能执行已经确定的制作目标，并能与实际参考文件和必要设置一起加入一个自包含 `Bxxx` 生成批次。
