# 生成结果质量检查

用于复用素材和镜头生成结果的详细审查。只检查当前对象实际适用的维度。

## 1. 剧情 / 镜头目的

- 这一结果是否完成当前镜头目的；
- 动作和信息是否与前因一致；
- 是否因为视觉奇观破坏原有剧情因果；
- 当前生成结果是否能够自然进入下一镜。

## 2. 人物

- 身份识别是否稳定；
- 发型、年龄感、身体比例和服装是否漂移；
- 表情、动作和情绪是否符合当前人物定义；
- 表演是否突然变成另一个角色的方式。

## 3. 对白 / 声音

- 台词是否与角色当前知道的信息一致；
- 音色、年龄感、音域和说话习惯是否稳定；
- 情绪变化是否有过渡；
- 口型、声音事件和画面时序是否可接受；
- 环境声或音乐是否覆盖重要对白。

## 4. 空间 / 连续性

- 人物、道具和产品位置是否与 Continuity In 一致；
- 门窗、家具和主空间关系是否无故改变；
- 运动方向是否发生无解释反转；
- 镜头出口是否足够明确，能够支持下一镜。

## 5. 产品 / 道具 / 机械

- 产品和道具结构是否保持；
- 是否增加不存在的接口、按钮、部件或文字；
- 陌生机械是否遵守既定活动方向和使用关系；
- 产品广告项目是否符合官方事实与结构边界。

## 6. 摄影

- 运镜是否实现预期信息功能；
- 镜头是否出现无目的漂移、旋转或持续推拉；
- 构图和焦点是否让观众看到真正重要的信息；
- 单个静帧好看不能替代整段动作正确。

## 7. 帧间稳定性

完整播放检查：

- 人脸 / 发型 / 服装是否在镜头内部逐帧漂移；
- 产品按钮、接口、Logo、道具结构是否随时间变形；
- 背景墙体 / 家具是否出现明显呼吸、融化或闪烁；
- 主体经过遮挡后是否保持同一身份和结构；
- 手与物体接触关系是否持续成立；
- 纹理 / 图案是否持续跳变；
- 动作和摄影速度是否出现无原因突变 / 冻结。

需要时暂停到问题帧定位，但最终判断必须基于完整播放，而不是只挑代表截图。

## 8. 处理方向

审查完成后只给出一种主处理方向：

- 采用；
- 采用并调整后续；
- 后期修复；
- 重新生成；
- 重写 SHOT / 素材定义 / 提示词。

重新生成前写清这一次只需要改变的主要变量，避免同时改动作、机位、参考图和风格而无法判断原因。
