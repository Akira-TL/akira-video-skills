# 采用、后期修复、重生成与重写边界

## 1. 采用

当前结果满足镜头 / 素材硬性要求，并且没有会继续污染后续制作的问题。

不要求像素级完美；普通可接受的随机差异不需要为了“再好一点”无限重生。

## 2. 采用并调整后续

适用于：

- 当前主要目的已经完成；
- 偏差不破坏角色身份、产品事实、剧情事实或关键结构；
- 下一镜可以自然从实际结果继续。

例如人物最终比计划多走半步，但位置仍合理。

此时记录实际出口，下一镜从实际画面继续。

## 3. 后期修复

适用于生成主体和动作基本正确，而且问题可以确定性修复，不需要重新赌一次随机生成。

常见情况：

- 字幕；
- Logo；
- 型号 / 参数；
- 简单裁切 / 重新构图；
- 音量；
- 配音替换；
- 简单声音同步；
- 可控遮罩 / 合成；
- 小范围可稳定修补且不会改变主体身份 / 产品结构的问题。

后期修复项写入当前采用记录，进入 `video-editing`。

## 4. 重新生成

适用于镜头 / 设计本身合理，但这一条执行失败。

典型情况：

- 人物身份明显错；
- 产品结构明显错；
- 主要动作没完成；
- 关键空间关系错；
- 物理 / 几何问题破坏主体；
- 摄影机没有完成核心信息任务；
- 原生声音承担当前镜头核心表现但严重失败。

重新生成前必须写清下一次主要改变什么。

## 5. 重写上游

适用于失败不是“运气不好”，而是当前要求本身不适合继续抽样。

典型情况：

- 同一镜头动作过多；
- 目标时长塞不下当前对白 / 动作；
- 参考素材互相冲突；
- 镜头空间逻辑不成立；
- 产品要展示一个没有官方结构依据的角度；
- 连续多条都出现同一种结构性失败；
- 当前模型 / 生成方式明显不适合任务。

回到真正归属来源：

- `video-design`；
- `video-materials`；
- `video-shot`；
- `video-script`；
- `video-advertising`；
- 或选择不同模型 / 生成模式。

## 6. 不要用后期掩盖硬错误

以下问题默认不能仅因为“后期也许能遮”就直接采用：

- 主角色脸错；
- 真实产品型号 / 结构错；
- 剧情关键动作完全错；
- 空间关系导致下一镜无法连接；
- 机械运动违反既定规则。

如果后期修复会接近重新制作主体本身，通常应该重生成或重写。

## 7. 不要为轻微问题无限重生

以下情况如果不影响当前制作，可以接受：

- 背景无关小物轻微变化；
- 非关键皱纹 / 发丝差异；
- 不影响连续性的微小站位偏差；
- 后期可以简单精确解决的文字 / Logo。

生成成本和随机性也是制作约束。

## 8. 迭代时一次改一个主要变量

例如：

- 只改动作表达；
- 只换参考图；
- 只缩短动作；
- 只减少摄影运动；
- 只改生成模式。

如果同时改角色图、镜头、时长、模型和提示词，就无法判断哪项真正解决了问题。

## 9. 连续失败升级

如果相同失败连续出现，逐步升级处理：

重新表达提示词
→ 调整参考 / 生成模式
→ 简化动作 / 拆镜头
→ 回到设计 / 脚本 / 产品事实。

不要无限重试同一结构。

## 完成标准

每个审片决定都选择成本和确定性最合理的路径；后期不掩盖硬错误，重生成也不替代上游设计修复。
