# 生成失败类型

用于审片时快速判断问题发生在哪里，以及下一轮应该改什么。它是人类可读分类，不要求项目维护错误代码数据库。

## 1. 身份漂移

表现：

- 人脸变化；
- 发型变了；
- 年龄感漂移；
- 同一角色像另一个人；
- 声音身份变成另一个角色。

优先检查：长期身份参考、参考冲突、设计与提示词是否一致。

## 2. 状态漂移

表现：

- 衣服从湿变干；
- 已经损坏的道具突然恢复；
- 手持物消失；
- 角色服装状态跳回旧状态。

优先检查：当前状态参考、上一镜实际出口、镜头连续性。

## 3. 空间漂移

表现：

- 门窗位置变化；
- 家具换边；
- 人物站位突然镜像；
- 前后镜头空间无法对上。

优先检查：地点设计、场景四视图、Continuity In / Out、摄影轴。

## 4. 产品 / 道具结构错误

表现：

- 按钮 / 接口增加；
- Logo 或型号错误；
- 部件数量改变；
- 陌生机械运动方向错误；
- 产品比例或工业结构变化。

真实产品优先回到官方素材 / 产品事实。复杂机械回到机制说明。

## 5. 动作失败

表现：

- 动作没有完成；
- 动作顺序错；
- 手与物体没有真正接触；
- 复杂交互变成穿模 / 消失；
- 镜头要求的主要事件没有发生。

优先检查：镜头动作是否过载、提示词是否清楚、是否需要拆镜头或关键帧。

## 6. 摄影失败

表现：

- 镜头无目的漂移；
- 机位与设计不符；
- 推近 / 拉远方向错；
- 焦点落在错误对象；
- 摄影运动掩盖关键动作。

优先检查：镜头摄影目的、模型适配提示词、是否应减小摄影复杂度。

## 7. 物理 / 几何失败

表现：

- 手脚异常；
- 物体穿模；
- 门 / 机械不按结构运动；
- 液体 / 布料 / 头发出现明显不合理运动。

关键主体或产品出现结构性物理错误通常不适合只靠后期掩盖。

## 8. 时间连续性失败

表现：

- 动作突然跳过；
- 前后速度不连续；
- 多镜头生成中的切点不合理；
- 角色在一个镜头内部突然换位置 / 状态。

优先检查动作量、时间线、镜头是否应该拆分。

## 9. 时间稳定性 / 纹理漂移

AI 视频常见问题不是单帧错误，而是播放过程中持续“变”。例如：

- 同一张脸在数秒内逐渐换人；
- 发型、衣服边缘持续抖动；
- 背景墙体、家具出现呼吸 / 融化；
- 产品按钮、接口、Logo 在帧间变化；
- 道具经过遮挡后重新出现时换形；
- 手指数量或手持关系来回变化；
- 纹理、文字和图案持续闪烁；
- 主体轮廓出现周期性拉伸 / 收缩。

这类问题必须看完整时间段，不能只比较首帧 / 尾帧或挑一张最好看的截图。

如果漂移发生在人物身份、真实产品结构或关键道具上，通常属于硬错误；背景无关微小纹理闪烁则根据当前镜头可见程度判断是否可接受 / 后期处理。

## 10. 运动节奏异常

表现：

- 人物突然加速 / 减速；
- 动作中途无原因冻结；
- 摄影机速度突变；
- 物体惯性不连续；
- 角色动作与声音时序突然错位。

优先检查当前时间线是否过载、模型是否适合该动作，以及是否应该拆镜头 / 减少运动。

## 11. 声音失败

表现：

- 角色音色漂移；
- 台词说错；
- 发音问题；
- 声音和动作不同步；
- 环境声 / 音效与画面不对应；
- 音乐遮挡对白。

判断是原生音频重生成更合理，还是后期替换更稳定。

## 12. 口型失败

表现：

- 口型与台词明显不符；
- 说话人混淆；
- 嘴部扭曲；
- 多角色同时出现错误口型。

可考虑重新生成、后配音 / 口型工具、换构图或拆镜头。

## 13. 文字 / Logo 错误

表现：

- 字符乱码；
- Logo 形状错误；
- 型号写错；
- 字幕错误。

默认优先后期用官方文件 / 可编辑文字修复；只有错误已经破坏产品本体结构或画面无法覆盖时才考虑重生成。

## 14. 风格漂移

表现：

- 同一片突然换材质；
- 色彩 / 光线语言脱离整片；
- 人物从写实变卡通；
- 同一世界摄影质感明显失控。

优先检查整体视觉方向、参考素材和当前提示词是否引入冲突风格。

## 15. 失败分类不是结论

同一种失败可能有不同处理方式。分类之后仍需按 `REPAIR-DECISIONS.md` 判断：

- 接受；
- 接受并调整后续；
- 后期修复；
- 重新生成；
- 重写上游。

## 完成标准

下一轮不是“再来一次”，而是能明确说明当前失败类型、最可能来源和主要要改变的变量。
