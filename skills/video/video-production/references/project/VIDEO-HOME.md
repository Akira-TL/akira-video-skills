# 单支视频 VIDEO.md

`video/videos/Vxxx_*/VIDEO.md` 是**这一支独立交付视频的唯一主要制作稿与简短当前摘要**，不是整个系列项目首页，也不是生成日志。

## 建议内容

- 视频 ID、工作名 / 正式标题；
- 用户 / 来源已经提出的目标、硬约束和创意要求；
- 上游来源 pointer 与采用范围；
- 剧情概要、场景顺序和必要正式正文；
- 使用的人物 / 地点 / 道具具体资产版本；
- 整片表达方向；
- 简单视频的唯一 Shot 表，或长视频的场景 / Shot 导航；
- 当前阻塞、待用户操作的 outbound pack、下一步。

没有真实信息的字段不为了模板完整填空。用户明确提出“哥特纸偶”“先剧情后产品”“4×15 秒”等创意 / 结构要求也属于正式输入，不能因为它看起来像导演问题而丢失。

## 长视频拆分

当正文已经影响阅读时，把详细动作、对白和场内 Shot 拆到 `scenes/SCxx.md`。拆出后 `VIDEO.md` 只留概要、顺序和链接；同一正文只维护一处。

## 当前摘要

只记录仍需恢复的当前事实，例如：`G003 returned, pending review`、`G004 pack waiting for user`、`G005 blocked by CHR01 reference`。历史 Generation 和已解决问题不不断追加；看 Git 和正式目录。

当前状态摘要不重复最终采用关系。简单视频若 Shot 表本身就在 `VIDEO.md`，它当然可以作为唯一正式 Shot 记录保存候选 / 当前使用来源；建立正式剪辑时间线后，最终采用关系迁到剪辑记录，Shot 表只保留叙事意图与剪辑引用。

## 上游来源

小说、章节、世界观、品牌资料等继续由原体系拥有。这里只写采用哪些章节 / 版本 / pointer 和本视频的改编结果，不复制上游正文。
