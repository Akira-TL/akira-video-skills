# 制作门禁

门禁只阻止已经知道的问题进入昂贵下一步，不建立全局 Stage、Gate 文件或状态数据库。Production 只运行当前分支适用的检查。

## 剧情 / 导演

有剧情时检查因果、人物已知信息、转折、对白容量、用户创意硬要求和整片表达是否互相冲突。方法：`video-director` / `video-script`。

## 视觉资产

需要稳定人物 / 地点 / 道具时，检查具体设计已足够、参考职责不冲突、必要四视图 / 状态图已经真实 Review、当前 Generation 引用具体资产版本。方法：`video-visual-design` + `video-review`。

## 产品

具体品牌 / 产品进入剧情或画面前，型号、功能、参数、结构与官方素材边界必须可靠；未知保持未知。方法：可选 `video-advertising`。

## Shot / 摄影

进入视频 Generation 前检查当前目标需要的 Shot 叙事意图、动作量 / 时长、必要连续性、机位 / 构图 / 运动和参考职责已经足够。方法：`video-storyboard` + `video-cinematography`。

## Generation

把 I 加入 B 批次前确认 Prompt 正文只有一处、实际参考文件版本真实存在、关键设置来自当前任务；build 后确认整个 B 批次自包含。具体模型动态能力按当前官方资料核验。

## 返回 Review

只对真实观察过的图片 / 视频 / 声音维度给结论；记录问题范围和返修层，不把 `usable` 写成最终 selected 状态。

## 最终剪辑 / 交付

正式时间线唯一记录最终实际采用；交付前检查内容连续性、声音、字幕 / Logo / 产品表达和当前明确技术规格。方法：`video-editing`。
