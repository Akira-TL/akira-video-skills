# 镜头覆盖策略

用于决定一个场次 / 动作到底需要几个镜头，以及每个镜头承担什么。

不要求按传统覆盖套路机械生成“大全景 + 中景 + 近景 + 特写 + 反应”。

## 1. 每个镜头先有唯一主要任务

一个镜头优先承担一个主要功能，例如：

- 建立空间；
- 展示人物关系；
- 完成关键动作；
- 展示产品操作；
- 让观众看到反应；
- 揭示信息；
- 建立质感；
- 完成转场。

一个镜头可以同时包含次要信息，但如果它要同时完成太多事情，优先拆分。

## 2. 建立镜头什么时候需要

需要让观众理解：

- 人在哪里；
- 人物之间什么位置；
- 门 / 出口在哪里；
- 产品 / 装置如何位于空间中；

才需要明确建立空间。

如果场景极简单、前镜已经建立、或短片只需要一个主体特写，不强制再生成一条大全景。

## 3. 中景 / 近景

中景适合同时看到人物表演和动作关系。

近景适合：

- 关键情绪；
- 微表情；
- 对白；
- 重要信息；
- 操作细节。

不要因为“电影感”无缘无故从宽景切近景；切近应带来新的信息或情绪。

## 4. 插入镜头 / 产品特写

插入镜头适合：

- 关键道具状态；
- 手部操作；
- 产品细节；
- 屏幕 / 按钮 / 结果；
- 需要隐藏时间压缩或剪辑接点。

真实产品特写还要遵守 `video-advertising/references/PRODUCT-SHOTS.md`，不为了特写生成未知结构。

## 5. 反应镜头

只有反应本身：

- 改变观众理解；
- 表现角色选择；
- 完成喜剧 / 情绪节奏；
- 给下一个动作建立动机；

才值得单独一镜。

不要每个动作后机械加一个“惊讶脸”。

## 6. B-roll / 气氛镜头

可以用于：

- 建立环境；
- 时间经过；
- 质感；
- 隐藏剪辑；
- 给旁白 / 音乐提供画面。

但不能用大量气氛镜头替代故事真正缺失的因果。

## 7. 覆盖和 AI 一致性成本

每增加一个镜头都会增加：

- 人物一致性风险；
- 场景一致性风险；
- 产品结构风险；
- 生成成本；
- 审片与剪辑工作。

所以不为“以后也许能用”无限生成 coverage。

但也不要为了减少一致性风险，把多个不同信息 / 动作强塞进一个过载镜头。

## 8. 为剪辑留下真正有用的备选

如果某个场次节奏很难预判，可以有意识准备少量备用：

- 一个简短反应；
- 一个产品插入；
- 一个空间建立；
- 一个可以作为转场的细节。

备用镜头必须有明确可能用途；没有用途的“多拍一点”只增加生成垃圾。

## 9. 蒙太奇

蒙太奇适合压缩：

- 重复过程；
- 时间经过；
- 多地点并行；
- 产品多个真实使用瞬间。

每个蒙太奇镜头仍应有清楚单一信息，不要求所有镜头拥有完整因果链。

蒙太奇镜头之间如果互不依赖，可以并行生成。

## 10. 同一动作不要重复展示

除非有意强调，不要：

- 宽景完整做一遍动作；
- 中景再完整做一遍；
- 特写再从头做一遍。

更自然的是把一个动作分给不同观察点：

- 宽景开始；
- 中景继续；
- 特写完成关键细节。

并按动作匹配切换。

## 11. 产品 / 广告常见覆盖

根据当前广告真正需要，可从这些功能里选：

- 问题 / 旧方法；
- 人物反应；
- 产品进入；
- 操作关系；
- 结果；
- 产品 hero shot；
- 品牌落版。

不是固定七镜模板。一个镜头能自然完成两个功能时可以合并；某个功能剧情里不存在就不补。

## 12. SHOTS.md 自检

镜头总览完成后从头扫一遍：

- 有没有两个镜头做同一件事；
- 有没有关键信息没有任何镜头承担；
- 有没有为了炫技增加的无功能镜头；
- 有没有单镜头承担过多动作；
- 有没有必要反应被漏掉；
- 产品 / 道具是否真正可读。

## 完成标准

镜头数量来自故事、动作、信息和剪辑需要；没有机械 coverage 套餐，也没有为了省一致性成本把镜头压得不可生成。
