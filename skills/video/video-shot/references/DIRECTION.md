# 镜头导演与连续性参考

只在镜头包含复杂摄影、动作、跨世界转场或连续性要求时读取。

## 1. 秒级设计

生成模型的镜头设计优先按可感知的时间段描述，例如：

- 0–2 秒：建立主体；
- 2–5 秒：动作发生；
- 5–7 秒：反应与结束。

不要把“第 37 帧抬手、第 52 帧眨眼”这类后期精度要求写成生成模型硬约束。帧级精修留给确定性后期。

## 2. 摄影机为什么运动

每次运镜应有明确目的。例如：

- 推近：发现或强化信息；
- 拉远：揭示空间或关系；
- 摇镜：跟随新的注意对象；
- 环绕 / 弧线：改变人物关系或展示空间；
- 变焦 / 焦点转移：改变观众注意力；
- 高低机位：改变权力、脆弱或威胁感；
- 微距：建立材质、细节或转场连接。

如果无法说明摄影机为什么现在要动，优先保持稳定构图。

## 3. Continuity In / Out

只记录相邻镜头必须继承的可见信息：

- 人物位置和朝向；
- 服装和明显状态；
- 手里拿着什么；
- 道具的打开/关闭、完整/损坏、液位等；
- 光线方向；
- 屏幕运动方向；
- 已经完成的动作。

尽量让状态单向推进，例如：

干燥 → 微湿 → 湿透；
完整 → 咬一口 → 一半 → 吃完。

如果需要逆转状态，必须有明确剧情或动作解释。

## 4. 实际生成结果与下一镜

采用的生成结果如果存在非关键偏差，下一镜从实际可见状态继续，而不是假装原设计已经完全执行。

但人物身份、产品真实结构、剧情事实或其他 Hard Constraint 被破坏时，不能为了省素材把错误画面升级为连续性依据。

## 5. 跨世界 / 大幅风格转场

存在多个视觉世界时，先明确哪些内容跨世界保持：

- 人物身份识别点；
- 关键形状；
- 关键颜色或纹理；
- 声音动机。

再明确必须变化的材质、光照、物理感和表现方式。

转场优先使用可见对应关系，例如颜色、纹理、形状、动作或声音匹配，而不是默认黑场或“突然醒来”。

## 6. 多镜头生成

模型能够在一次生成中产生多个硬切或内部镜头，不等于项目结构也要合并。

如果生成结果最终包含两个独立剪辑镜头，项目仍应能把它们作为可理解的镜头管理；模型生成方式不能反过来决定长期项目语义。
