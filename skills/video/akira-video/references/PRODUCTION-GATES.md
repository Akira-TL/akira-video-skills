# 制作门禁

门禁用于阻止已经知道的上游问题继续进入昂贵生成，不要求项目额外建立 Gate 文件或状态数据库。

只运行当前项目适用的门禁。

## 1. 脚本门禁

适用于有剧情 / 人物关系 / 广告故事的项目。

进入大规模视觉设计、素材和镜头制作前，确认：

- 关键事件因果成立；
- 冲突存在真实升级；
- 关键转折来自人物选择、行动后果或既有规则；
- 人物没有突然知道未知信息；
- 结尾需要回收的元素已经建立；
- 对白没有承担大段设定解释。

Owner：`video-script`。

## 2. 视觉设计门禁

需要重复角色 / 场景时，进入长期生图前确认：

- 角色 / 地点已经有具体视觉设计，不是泛化描述；
- 主要角色之间有足够识别差异；
- 场景空间 / 材质 / 光线能够跨镜头维持；
- 整片视觉方向没有互相冲突；
- 复杂世界 / 机械的长期规则已经明确。

Owner：`video-design`。

## 3. 产品门禁

只适用于具体产品 / 品牌项目。

进入产品相关剧情与生成前确认：

- 型号明确；
- 核心功能和参数有官方依据；
- 未知内容保持未知；
- AI 生成参考没有被当成产品事实；
- 产品在剧情中解决的是已建立问题；
- 产品镜头不会生成未知工业结构。

Owner：`video-advertising`。

## 4. 素材门禁

进入批量镜头生成前确认：

- 必须长期稳定的角色 / 场景 / 产品有足够参考；
- 身份与状态已分开；
- 严格四视图（如果使用）已经通过一致性检查；
- 参考素材之间没有身份竞争；
- 不必要的公共素材没有被提前生成。

Owner：`video-materials` + `video-review`。

## 5. 镜头门禁

每个镜头进入视频生成前确认：

- 镜头目的明确；
- 动作量与目标时长相容；
- 连续性入口 / 出口足够清楚；
- 参考素材职责清楚；
- 硬性约束与偏好区分；
- 明显后期任务没有塞给生成模型。

Owner：`video-shot`。

## 6. 声音门禁

需要跨镜头角色声音时确认：

- 基础音色 / 年龄感 / 音域 / 节奏已有统一定义；
- 情绪变化没有被误当成新的声音身份；
- 当前对白由脚本拥有，声音 Skill 只负责表演；
- 当前工具不能稳定声音时有后配方案。

Owner：`video-audio`。

## 7. 生成结果门禁

每批图片 / 视频回来后基于实际 artifact 检查：

- 身份、结构、空间和状态；
- 动作、摄影和时序；
- 连续性入口 / 实际出口；
- 产品事实（适用时）；
- 声音 / 口型（适用时）。

只有实际观察过的维度可以写成通过。

Owner：`video-review`。

## 8. 最终成片门禁

进入最终交付前基于真实成片从头到尾检查：

- 故事 / 信息连续性；
- 镜头节奏和衔接；
- 对白、音乐、环境声和音效；
- 字幕 / Logo / 型号 / 参数；
- 产品表达；
- 画幅、分辨率、时长和平台要求。

Owner：`video-editing`。

## 门禁失败

失败回到真正 owning source 修复。

不要：

- 在提示词里掩盖脚本问题；
- 在后期里静默改写上游事实；
- 因为已经生成很多结果而降低人物 / 产品 / 连续性要求。

## 完成标准

昂贵的下一阶段只建立在已经满足的上游条件上；项目仍保持轻量，不需要额外 Gate 状态文件。
