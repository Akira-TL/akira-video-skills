# 多语言与本地化版本

当同一视频需要字幕、旁白、配音或正式成片的多语言版本时使用。

目标是复用同一项目的脚本、视觉设计、镜头与媒体，只为语言差异增加最少必要文件；不为每种语言复制整套 `video/`。

## 1. 先确定源语言版本

项目先有一个当前权威源语言，例如：

- 中文；
- 英文；
- 日文。

源语言的剧情、人物关系、产品事实和镜头结构仍由正常项目文件拥有。

多语言版本不成为新的剧情事实来源。

## 2. 只做字幕时

不需要复制脚本或镜头。

最终字幕文件可以直接放 `video/edit/`，例如：

`subtitles.en-US.srt`
`subtitles.ja-JP.srt`

简单项目不再创建 `subtitles/` 子目录；只有语言 / 文件数量已经影响浏览时才按需增加。

## 3. 需要配音 / 旁白翻译时

目标语言文本需要长期审核时，可以在 `video/script/` 保存：

`SCRIPT.en-US.md`
`SCRIPT.ja-JP.md`

或只保留目标语言对白 / 旁白的最小 localization 文件。

不要复制：

- `CHARACTERS.md`；
- `SCENES.md`；
- `SHOTS.md`；
- 全部 `SHOT.md`；

除非目标语言真的导致镜头设计变化。

## 4. 翻译不是逐字替换

目标语言优先保持：

- 原意；
- 角色身份；
- 语气；
- 信息层级；
- 产品事实；
- 品牌用语；
- 喜剧 / 包袱功能。

允许为了自然口语调整：

- 句式；
- 词序；
- 省略；
- 停顿；
- 口语表达。

不允许为了“更顺”改变：

- 产品功能；
- 数值 / 参数；
- 人物关系；
- 剧情事实；
- 法务 / 客户明确文案。

## 5. 产品与品牌文案

产品型号、参数、功能与品牌正式用语仍回到 `video-advertising` 的已核验事实。

目标语言已有官方译名 / 正式品牌文案时优先使用官方版本，不自行创造近义词。

未知官方译法时明确标记需要确认，不静默编造。

## 6. 人名、地名与术语表

只有项目确实存在大量专名 / 术语时才维护简短术语表，例如：

```markdown
## 术语
- CHR01：李青 / Li Qing
- PROD01：官方英文型号保持原样
- 灵脉：spirit meridian（仅当前项目约定）
```

术语表可以放在目标语言脚本文件顶部；不默认建立独立翻译数据库。

## 7. 不同语言时长不同

翻译后真实朗读时长可能明显变化。

处理顺序：

1. 先自然翻译；
2. 实际朗读 / TTS 试听；
3. 如超时，优先压缩冗余表达；
4. 仍超时，再考虑声音跨镜头、微调镜头长度或重构句子；
5. 不用异常快语速硬塞。

目标语言脚本仍要服从 `DIALOGUE-TIMING.md` 的自然时长原则。

## 8. 口型

### 画外音 / 旁白

通常可以直接复用原画面，只替换声音和字幕。

### 看不清嘴部的镜头

可以根据可接受程度直接配音，不一定重生成。

### 明显正面口型

如果目标语言口型差异明显，选择：

- 当前工具可靠的口型同步；
- 重生成目标语言镜头；
- 换成更安全构图；
- 后期切到反应 / 插入镜头；

而不是默认让不匹配口型直接通过。

## 9. 角色声音本地化

不同语言可以由不同配音者 / 声音模型承担，但尽量保持同一角色的：

- 年龄感；
- 性格；
- 能量；
- 节奏；
- 情绪范围。

不要求不同语言具有完全相同声纹；角色身份的**表演特征**比机械复制声音更重要。

如果同一个多语声音模型确实能可靠保持身份，可以复用，但不作为通用前提。

## 10. 镜头专属配音

单镜头目标语言对白放对应镜头，例如：

`dialogue.en-US.wav`
`dialogue.ja-JP.wav`

最终进入剪辑后也可以只由后期工程引用，不要求每种语言都复制视频。

## 11. 全片旁白

目标语言旁白可以放：

`video/edit/voiceover.en-US.wav`
`video/edit/voiceover.ja-JP.wav`。

临时候选仍留一次性生成包；选中后再用稳定语言名。

## 12. 字幕从最终声音 / 文本生成

字幕必须与该语言的最终对白 / 旁白一致。

不要：

- 先翻字幕；
- 后改配音；
- 最后忘记同步字幕。

字幕时间轴按目标语言实际声音重新检查。

## 13. 字幕不是配音逐字稿时

有的平台 / 项目允许字幕做轻度压缩。

可以减少：

- 口头重复；
- 不影响意思的语气词；
- 过长句子。

但不能改变产品事实、剧情信息或角色意思。

## 14. 图文 / 片尾本地化

标题、字幕、产品文案和片尾主卡由 `video-editing` 确定性替换。

文字长度变化时重新检查：

- 字号；
- 换行；
- 安全区；
- 出现时长；
- Logo / 产品布局。

不要让英文短标题直接替换成更长语言后溢出原版版式。

## 15. 需要重新生成画面的情况

只有目标语言真的改变画面时才复制 / 生成语言专属画面，例如：

- 明显口型；
- 场景内必须出现准确文字；
- 产品 UI 必须显示目标语言；
- 演员手持实体文字材料；
- 文化本地化需要改变视觉内容。

其余情况优先复用同一视频源。

## 16. 成片与语言后缀命名

字幕、旁白、正式成片和多画幅 + 多语言组合的语言后缀统一按 [`../project/NAMING.md`](../project/NAMING.md)；只有同一项目真正并存多个语言版本时才增加语言标签，不在这里维护第二套命名规则。

## 17. 技术 QC

每个语言成片分别检查：

- 正确语言；
- 音轨；
- 字幕；
- 图文；
- 片尾；
- 时长；
- 画幅；
- 产品型号 / 参数；
- 是否误混源语言占位音频 / 字幕。

## 18. 不复制整个 edit 工程的原则

后期软件能在一个工程里安全管理多语言轨道 / 序列时，可以共用工程。

只有：

- 客户要求；
- 工程结构实际需要；
- 不同语言视觉版本差异很大；

才拆独立后期工程。

## 完成标准

多语言版本共享同一故事、设计和镜头资产；翻译自然但不改事实，时长与口型经过真实检查，字幕 / 图文与最终音轨一致，不为每种语言复制一套项目。
