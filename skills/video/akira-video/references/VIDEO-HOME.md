# VIDEO.md

`VIDEO.md` 是项目根目录的视频制作首页，不是日志。

推荐结构：

```markdown
# Video

## 项目定义

## 交付要求

## 来源与限制

## 当前进度

## 当前工作

## 阻塞项

## 关键决定

## 导航
```

## 项目定义

只记录会影响整片制作的字段，例如：

- 项目名称；
- 视频类型；
- 上游来源（小说、章节、brief、产品资料等 pointer）；
- 目标观众；
- 希望观众最后记住什么 / 感受到什么；
- 目标总时长与允许范围；
- 画幅比例；
- 目标平台 / 客户 / 比赛；
- 当前主要视觉方向 pointer；
- 当前计划使用的主要生成工具（如果已决定）。

没有真实信息的字段不为了模板完整而编造。

## 交付要求

记录真正影响最终输出的要求，例如分辨率、格式、字幕、Logo、片尾、比例版本、时长限制和其他客户 / 平台要求。

## 来源与限制

这里只记录当前制作真正需要记住的来源边界：

- 上游故事 / 小说 / 品牌资料在哪里；
- 官方产品素材在哪里；
- 用户提供或授权使用的参考素材；
- 音乐、字体、人物肖像或第三方素材的已知授权限制；
- 明确不能夸大、不能出现或必须保留的内容。

不把来源正文复制进 `VIDEO.md`，只保留短说明和 pointer。

## 当前状态部分

`当前进度`、`当前工作`、`阻塞项` 与 `关键决定` 只保留仍影响后续制作的内容，不写成历史日志。已经失效的旧决定由 Git 保存。

## 导航

只指向当前项目真实存在的人类可读入口；没有对应内容时不要创建空目录或占位文件。
