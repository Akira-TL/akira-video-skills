# 场景视觉设计

## 1. 从叙事功能开始

场景先回答：

- 为什么故事必须发生在这里；
- 观众第一眼必须知道什么；
- 人物在这里能够做哪些关键动作；
- 哪些空间关系会进入后续 Shot；
- 这个场景与其他场景最重要的视觉差异是什么。

## 2. 空间骨架

先决定容易保持的空间骨架：

- 大体尺寸；
- 门、窗和主要通道；
- 主要家具 / 建筑 / 地形；
- 人物活动区域；
- 关键道具位置；
- 主摄影轴和常用观察方向。

需要时用简单平面图或文字方位说明，但不为了形式建立复杂建筑图。

## 3. 材质和视觉语言

明确主要表面：

- 墙、地面、天花 / 天空；
- 木、石、金属、布、玻璃、塑料等主要材质；
- 新旧、磨损、潮湿、干燥、洁净等状态；
- 风格化世界中的材料规则。

同一场景多个角度必须遵守同一材料逻辑。

## 4. 色彩和照明

记录：

- 主色；
- 辅助色；
- 重点色；
- 主光来源；
- 主光方向；
- 时间感；
- 冷暖关系；
- 允许变化的局部光源。

光线可以随剧情变化，但变化必须有来源，不让每个 Shot 随机换一套摄影棚灯光。

## 5. 视觉锚点

每个重要场景优先建立少量容易识别的视觉锚点，例如：

- 特殊窗形；
- 一组固定柜体；
- 中央长桌；
- 独特楼梯；
- 特定山体 / 建筑轮廓。

锚点用于跨镜头确认“这是同一个空间”，不要靠大量随机小物件实现一致性。

## 6. 镜头可用性

场景设计同时考虑后续镜头：

- 是否有足够正反打方向；
- 人物能否自然进出；
- 产品 / 道具能否合理出现；
- 重要动作是否有可见空间；
- 背景是否会吞没人物轮廓；
- 多个镜头是否能维持相同空间关系。

## 7. 与 Shot 的边界

公共场景设计只保存跨镜头稳定的空间与视觉规则。

某一 Shot 独有的临时物件、特殊烟雾 / 破坏、一次性光效、特定摄影机位置，优先留在对应 `SHOT.md`，不把公共场景设计变成所有镜头细节的堆积。
