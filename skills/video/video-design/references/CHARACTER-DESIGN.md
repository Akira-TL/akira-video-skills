# 角色视觉设计

## 1. 从角色功能开始

先确认当前视频中的角色：

- 在故事里做什么；
- 观众第一次看到时应该立刻读出什么；
- 与其他角色最重要的视觉差异是什么；
- 哪些身份、时代、职业或生活状态必须通过外观被看见。

不要从“随机发型 + 随机服装 + 好看”开始拼角色。

## 2. 轮廓与比例

先形成容易区分的整体轮廓，再进入面部细节：

- 身高感与身体比例；
- 肩、腰、腿等大体比例；
- 发型外轮廓；
- 服装外轮廓；
- 是否有稳定配件。

多个主要角色同框时，应尽量避免相似的身高、发型轮廓、服装剪影和大面积配色导致身份混淆。

## 3. 面部与发型

面部设计只保留足够稳定和可辨认的结构：

- 脸型；
- 眼、眉、鼻、嘴的大体结构；
- 年龄相关特征；
- 明显但合理的识别点；
- 发际线、长度、层次、刘海、扎发 / 披发结构。

不要依赖每次生成都很难稳定的小饰纹或大量微小特征来承担身份。

## 4. 服装系统

服装设计同时考虑：

- 人物身份和经济 / 职业状态；
- 时间、气候与场景；
- 动作需求；
- 多镜头生成稳定性；
- 与场景背景的分离度。

优先固定：

剪裁 → 层级 → 材质 → 大面积颜色 → 配件位置。

小纹理和复杂印花只有确实承担设计作用时再加入。

## 5. 色彩与材质

给角色建立少量主色、辅助色和稳定材质，而不是每个部位一个颜色。

色彩应同时考虑：

- 人物性格 / 身份；
- 场景主色；
- 多角色之间区分；
- 不同光照下是否仍能辨认。

## 6. 状态变化

基础身份与剧情状态分开。

例如：

- 基础身份；
- costume-a / costume-b；
- normal / damaged；
- dry / wet。

状态变化必须建立在同一个角色设计上，不重新随机生成一个“相似的人”。

## 7. 可生成性检查

确认：

- 轮廓足够清楚；
- 特征数量不过载；
- 左右配件关系明确；
- 服装层级模型能够理解；
- 关键颜色和材质不互相冲突；
- 四视图能够表达完整身份。

如果设计只有在一张精修概念图中成立，却无法跨多个镜头稳定复现，应优先简化设计，而不是把一致性压力全部交给 Prompt。
