# 空间与机械设计

只在主场景空间关系或陌生装置会直接影响多个镜头时使用。

## 1. 空间关系

复杂主场景可以在场景设计文件中增加简单空间图或文字方位：

```text
                NORTH

WEST        MAIN SPACE        EAST

                SOUTH
```

按当前镜头真实需要标记：

- 门；
- 窗；
- 主要角色初始区域；
- 主要道具；
- 产品位置；
- 主光方向；
- 主要摄影轴；
- 可移动区域；
- 禁止穿越区域。

空间图只服务连续性，不要求建筑级精确 CAD。

反打镜头不能自动把人物左右关系、门窗位置或家具布局镜像交换。

## 2. 陌生机械 / 装置

模型可能不理解的装置，建立长期机制说明，至少写清：

- 固定部件；
- 移动部件；
- 移动方向；
- 移动范围；
- 动力来源；
- 控制方式；
- 角色怎样进入 / 握持 / 操作；
- 角色姿势；
- 操作前状态；
- 操作中状态；
- 操作结束状态；
- 其他角色位置；
- 一次允许处理多少主体；
- 故障时会发生什么；
- 绝对不会发生什么。

## 3. 机械提示词模板

需要把陌生装置交给生图 / 视频模型时，可以从长期机制说明编译下面的简化模板：

```text
这不是概念艺术设计，而是需要保持机械连续性的影视道具。

固定结构：
<描述>

活动结构：
<描述>

只能进行的运动：
<方向 / 范围>

绝对禁止的运动：
<方向 / 关系>

操作关系：
角色动作 A
→ 部件 B
→ 连接 C
→ 部件 D 发生动作

如果角色停止动作：
→ 设备发生什么

人物 / 物体必须以以下姿势进入或使用：
<明确描述>

不允许模型自行改变使用姿势。
```

镜头提示词只引用当前镜头真正需要的机械关系，不必每次复制完整机制说明。

如果角色停止动作，也应明确设备随后怎样表现。不要让不同镜头各自重新设计同一个装置的结构、运动方向和使用姿势。
