# 空间与机械设计

只在主场景空间关系或陌生装置会直接影响多个镜头时使用。

## 1. 空间关系

复杂主场景可以在场景设计文件中增加简单空间图或文字方位：

```text
                NORTH

WEST        MAIN SPACE        EAST

                SOUTH
```

按当前镜头真实需要标记：

- 门；
- 窗；
- 主要角色初始区域；
- 主要道具；
- 产品位置；
- 主光方向；
- 主要摄影轴；
- 可移动区域；
- 禁止穿越区域。

空间图只服务连续性，不要求建筑级精确 CAD。

反打镜头不能自动把人物左右关系、门窗位置或家具布局镜像交换。

## 2. 陌生机械 / 装置

模型可能不理解的装置，建立长期机制说明，至少写清：

- 固定部件；
- 移动部件；
- 移动方向；
- 移动范围；
- 动力来源；
- 控制方式；
- 角色怎样进入 / 握持 / 操作；
- 角色姿势；
- 操作前状态；
- 操作中状态；
- 操作结束状态；
- 其他角色位置；
- 一次允许处理多少主体；
- 故障时会发生什么；
- 绝对不会发生什么。

## 3. 机械 Prompt 核心

镜头 Prompt 只引用当前镜头真正需要的机械关系，例如：

角色动作 A → 部件 B → 连接 C → 部件 D 发生动作。

如果角色停止动作，也应明确设备随后怎样表现。

不要让不同 Shot 各自重新设计同一个装置的结构、运动方向和使用姿势。
