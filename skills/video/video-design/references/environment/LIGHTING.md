# 灯光与曝光设计

用于需要跨镜头保持光线逻辑、人物肤色、产品反光或明确时间 / 天气状态的场景。

基础灯光属于地点 / 世界设计；只服务一个镜头的临时光效写进对应 `SHOT.md`。

## 1. 先确定光从哪里来

优先使用有来源的光：

- 窗；
- 太阳 / 天空；
- 顶灯；
- 台灯；
- 店铺灯箱；
- 屏幕；
- 火；
- 车灯；
- 舞台灯；
- 世界设定中的特殊光源。

不是每一束电影感轮廓光都必须在现实里看见灯具，但整体方向和逻辑应可解释。

## 2. 基础灯光至少考虑

- 主光来源；
- 主光方向；
- 软 / 硬；
- 冷 / 暖；
- 大体亮度关系；
- 环境填充；
- 背景与主体分离；
- 时间 / 天气。

不要求所有场景写成专业灯光图；只记录后续生成真正需要稳定的部分。

## 3. 人物曝光

人物是叙事主体时至少保证：

- 面部关键表情可读；
- 肤色不过曝 / 死黑；
- 眼睛在需要时可见；
- 强逆光下仍有足够人物信息。

如果设计故意让人物成为剪影 / 黑暗轮廓，明确它是叙事选择，而不是生成失败。

## 4. 产品曝光

真实产品额外检查：

- 轮廓可读；
- 表面材质被正确表现；
- 高光不过度遮掉 Logo / 接口 / 结构；
- 黑色产品不要融进黑背景；
- 白色产品不要在高光中失去边缘；
- 金属 / 玻璃反射不伪造不存在的结构。

反光产品优先通过大面积柔和高光展示形体，不为了炫技让随机硬反射在不同帧跳动。

## 5. 主光方向是连续性状态

同一地点、同一时间段的相邻镜头默认保持主要光线方向。

例如：

`LOC01：主光从世界空间东侧窗户进入。`

反打后：

- 画面左右高光 / 阴影关系可能变化；
- 但世界空间中的窗户仍在东侧；
- 不因为镜头翻面就把太阳改到另一边。

## 6. 色温与世界状态

同一场景可以因为：

- 时间变化；
- 天气；
- 灯具开关；
- 剧情事件；

改变色温和亮度。

变化必须有来源。

不要在没有时间变化的连续镜头里一镜暖黄、一镜冷蓝，只因为模型随机风格不同。

## 7. 白天 / 夜晚状态

同一个地点的 day / night：

- 空间结构不变；
- 门窗 / 家具不变；
- 视觉锚点不变；
- 光源和环境亮度改变。

如果需要长期稳定，可以生成 `LOC01_day.png / LOC01_night.png` 状态参考，但仍然是同一个 `LOC01`。

## 8. 实用光源（Practical）

画面里可见的灯具可以帮助模型理解光线来源，例如：

- 台灯照亮桌面；
- 冰箱内部冷光；
- 霓虹招牌；
- 路灯。

但不要为了说明光源在画面里塞入大量无用灯具。

## 9. 轮廓光 / 背光

背光和轮廓光适合分离主体、强化材质和情绪。

使用时检查：

- 是否与场景光源方向相容；
- 是否在反打中仍合理；
- 是否把产品边缘烧白；
- 是否让人物脸完全丢失。

## 10. 动态光

移动灯光、屏幕闪烁、车灯扫过、火光等动态光要明确：

- 来源；
- 时间变化；
- 影响对象；
- 是否需要跨镜头继续。

不要只写“dramatic flickering light”而没有实际光源 / 节奏。

## 11. 光线与材质

材质需要不同灯光可读性：

- 金属：依赖反射形状；
- 玻璃：依赖边缘和环境反射；
- 布料：依赖柔和阴影 / 纹理；
- 皮肤：避免过硬高光破坏身份；
- 塑料：避免随机高光让产品看起来像不同材质。

视觉设计和灯光应一起考虑，不在后期才第一次发现材质完全不可读。

## 12. 曝光与调色分开

后期可以修：

- 轻微曝光差异；
- 白平衡；
- 饱和度；
- 对比度。

但不能用调色真正修复：

- 主光方向完全错误；
- 阴影结构不可能；
- 产品反射把结构画错；
- 人物脸已经严重欠曝 / 过曝没有信息。

这些属于生成 / 灯光设计问题。

## 13. 多世界灯光

多个视觉世界可以有不同光线规则，例如：

- 现实世界自然柔光；
- 梦境世界无明确来源的体积光；
- 纸偶世界平面顶光。

每个世界内部仍应稳定；世界规则变化必须来自设计，不是每镜随机。

## 14. SHOT.md 临时灯光

只属于当前镜头的特殊灯光写在 `SHOT.md`，例如：

```text
临时光效：CHR01 打开冰箱，冷白内部光在 1.5 秒时亮起，只照亮脸和双手。
```

它不自动改写 `LOC01` 的基础灯光设计。

## 15. 提示词

生成提示词只写当前画面需要的可见光线关系，例如：

```text
柔和的清晨窗光从画面右侧进入，轻柔照亮人物面部；房间保持柔和环境填充，不出现强硬轮廓光。
```

最终模型适配器如果明确更适合英文或特定摄影术语，再把这一可见灯光关系编译成对应模型表达。

不要把：

“cinematic, dramatic, moody, beautiful lighting”

当成完整灯光设计。

## 16. 灯光验收

跨镜头检查：

- 主光方向；
- 阴影方向；
- 人物肤色；
- 产品颜色 / 反射；
- day / night / weather 状态；
- 动态光是否按时间发生；
- 是否出现无来源闪烁 / 光线跳变。

## 完成标准

光线有可解释来源、能够跨镜头保持世界空间逻辑，并让人物 / 产品真正可读；后期只修轻微统一问题，不替代错误灯光结构。
