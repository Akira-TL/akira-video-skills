# 视频脚本层文件职责

`video/script/` 只创建当前项目真正需要的文件。

## SCRIPT.md

回答“视频里发生什么”。

适合保存：

- 改编来源与范围；
- 一句话梗概；
- 当前视频的场次顺序；
- 场次内动作；
- 角色对白；
- 关键因果与转折。

不在这里详细设计摄影机、焦段、模型参数和参考图；这些属于 Shot / Generation。

## CHARACTERS.md

回答“角色在本片怎么演”。

适合保存：

- 本片身份阶段；
- 当前目标、担忧和行为方式；
- 表演范围与禁止表演；
- 对白节奏；
- 角色弧光；
- 基础声音方向 pointer。

角色具体脸、发型、服装、比例和色彩方案由 `video-design` 的 `CHRxx_design.md` 拥有，不在这里复制第二份完整视觉设计。

## SCENES.md

回答“当前视频会使用哪些场次 / 场景，它们在故事里承担什么”。

适合保存：

- Scene ID；
- 地点 / 时间；
- 场景叙事功能；
- 当前出场角色；
- 关键动作 / 道具；
- 相邻场景需要知道的空间或状态关系；
- 对应 `LOCxx_design.md` pointer。

完整视觉材质、色彩、光线和空间设计由 `video-design` 拥有。

## SHOTS.md

回答“整片有哪些镜头”。

每条保持总览级信息：

- Shot ID；
- 目标时长；
- 镜头目的；
- 主要画面 / 动作；
- 必要的前后关系。

详细机位、动作时间、参考素材、Continuity In / Out 和 Hard Constraints 进入对应 `video/shots/<shot-id>/SHOT.md`。

## 简单项目

一个 6 秒产品镜头可能只需要 `SHOTS.md`，甚至用户已经直接给出清楚镜头时可以不建立完整 `SCRIPT.md / CHARACTERS.md / SCENES.md`。

文件存在与否由真实制作内容决定，不由模板决定。
