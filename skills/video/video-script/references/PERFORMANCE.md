# 人物表演设计

当视频包含人物表演、情绪变化、关系冲突或重要反应时使用。

目标是把“情绪词”转换成可以被演员 / 生成模型表现、可以被镜头观察的行为。

## 1. 不把情绪词当表演指令终点

“紧张”“伤心”“开心”“愤怒”只是状态标签，不足以指导镜头。

继续问：

- 身体变紧还是放松；
- 看向谁 / 避开谁；
- 手在做什么；
- 呼吸怎样；
- 说话变快还是变慢；
- 是主动靠近还是后退；
- 是否试图隐藏情绪；
- 情绪变化发生在哪一个具体事件后。

## 2. 行为节拍

复杂表演可以拆成少量行为节拍，例如：

发现异常
→ 先假装没事
→ 再确认一次
→ 意识到问题严重
→ 停下手里的动作
→ 做决定。

每个节拍对应可见变化，不需要给模型输入完整心理学解释。

## 3. 情绪要有触发点

不要让角色在镜头中无原因突然换情绪。

情绪变化应来自：

- 新信息；
- 对方一句话；
- 一个动作结果；
- 产品 / 道具状态变化；
- 角色自己的决定。

如果情绪变化跨镜头，前一镜出口和下一镜入口要能接上。

## 4. 反应先于台词

真实表演往往是：

刺激
→ 微小身体 / 视线反应
→ 判断
→ 说话 / 行动。

不是所有刺激后立刻说一句解释性台词。

短片时长有限时也可以只保留最关键反应，不要求每个刺激都做完整表演链。

## 5. 身体与视线

镜头里需要稳定的表演关系时，明确：

- 身体朝向；
- 头部朝向；
- 视线目标；
- 重心；
- 手的位置；
- 与另一个角色 / 产品的距离。

“看着产品”比“对产品感到惊讶”更容易形成可验证动作。

## 6. 微表情按镜头尺度使用

近景可以使用：

- 眼神变化；
- 眉毛；
- 嘴角；
- 短暂停顿；
- 吞咽；
- 轻微呼吸变化。

远景里不要把叙事依赖在只有近景才能看见的微表情上。

## 7. 不要每个人都演满

多人场景中，当前叙事重点只有一个时：

- 主体完成主要表演；
- 其他角色保持简单、可读的反应；
- 不要求所有人同时大幅动作。

这样既减少视觉噪声，也降低多角色生成失败。

## 8. 表演与对白一致

说话方式要匹配动作：

- 角色嘴上说“没事”，身体却明显回避，可以是有意矛盾；
- 如果没有叙事意图，不要让台词和身体情绪随机相反。

语速、停顿与声音身份由 `video-audio` 协作；对白内容仍由 `video-script` 拥有。

## 9. 产品操作时的表演

人物使用产品时，先保证真实操作，再加情绪。

例如：

发现问题
→ 拿起产品
→ 找到正确握持 / 操作位置
→ 完成实际操作
→ 看到结果
→ 再产生反应。

不要让人物一边高强度表演、一边做复杂精细操作，导致手物关系和产品结构都崩。

## 10. 喜剧

喜剧通常依赖：

- 建立预期；
- 停顿；
- 反差；
- 角色认真对待荒谬情况；
- 回收。

不要只靠夸张表情代替包袱结构。

## 11. 表演连续性

相邻镜头检查：

- 情绪强度；
- 身体紧张程度；
- 呼吸；
- 视线；
- 已完成的动作；
- 是否已经知道某件事。

人物不能前一镜刚崩溃，下一镜无事件过渡突然完全平静。

## 12. 写进哪里

长期人物表演倾向：`CHARACTERS.md`。

当前场次的行为 / 对白：`SCRIPT.md`。

单镜头具体表演节拍、视线和身体动作：对应 `SHOT.md`。

不要把每个镜头动作写回人物长期定义。

## 完成标准

人物表演能被镜头观察、由事件触发并保持连续；表演不是一串情绪形容词，也不会为了“戏多”同时制造过多身体动作和对白。
