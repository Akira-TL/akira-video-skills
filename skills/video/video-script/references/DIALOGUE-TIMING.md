# 对白时长与口型规划

当镜头包含可见说话人物、同步语音、长对白或多角色对话时使用。

## 1. 对白必须能放进镜头

写完对白后，不只看文字长度，要判断角色以当前情绪、语速和停顿真实说出来需要多久。

优先使用：

- 实际朗读；
- 已有角色声音试读；
- 当前语音工具的试听结果。

不要只用固定“每分钟多少字”替代真实语速，因为语言、情绪、停顿和表演差异很大。

如果一句对白明显超过当前镜头可用时间，优先选择：

- 缩短对白；
- 把部分信息改成动作；
- 如果镜头节奏允许，延长目标时长；
- 拆成两个镜头；
- 让声音跨切点延续；
- 改成画外音 / 旁白（前提是剧情允许）。

不要为了塞进镜头强行让角色以不自然速度念完。

## 2. 可见口型

需要人物口型明显同步时，镜头设计同时考虑：

- 脸是否足够清楚；
- 嘴部是否长期被遮挡；
- 摄影机是否在对白期间大幅旋转 / 远离；
- 角色是否同时做过多复杂动作；
- 当前模型 / 后期工具是否真的支持稳定口型。

如果口型不是核心信息，可以用：

- 侧后方构图；
- 中远景；
- 画外说话；
- 反应镜头；
- 后期单独配音。

不要为了展示原生音频能力，让一个本来不需要近景说话的镜头变成高风险口型镜头。

## 3. 多角色对话

同一镜头包含多个人说话时，必须明确：

- 谁先说；
- 谁打断；
- 是否重叠；
- 镜头此刻看谁；
- 另一个人的反应是否需要看见。

如果模型容易混淆说话人，优先拆镜头或后配声音，不把所有对白都塞进一个生成请求。

## 4. 情绪影响时长

同一句话在不同情绪下时长可能显著不同：

- 紧张会出现停顿或吞咽；
- 生气可能加速或重读；
- 犹豫会有半句、停顿和改口；
- 悲伤可能降低音量并延长空白。

对白时长规划必须与 `video-audio` 的角色声音定义和当前表演一致。

## 5. 声音跨镜头

一句话不一定必须完全落在同一个画面里。

粗剪阶段可以使用声音先行剪辑（J-cut）或声音延后剪辑（L-cut），让对白自然跨镜头；前提是画面因果和人物位置仍然清楚。

## 6. 字幕不是生成任务

字幕、长文字和精确排版默认由 `video-editing` 后期完成。

视频生成提示词只负责角色真正说什么、怎么说和声音事件，不要求模型在画面中同步生成字幕。

## 7. 进入生成前检查

包含对白的镜头至少确认：

- 台词在目标时长内能自然说完；
- 表演动作与说话同时发生是否合理；
- 口型要求与当前构图 / 模型能力相容；
- 多角色说话人不会混淆；
- 当前对白对应正确角色声音身份。

## 完成标准

镜头不会因为台词过载、强行快读或高风险口型而失去可生成性；需要跨镜头或后配的声音在制作前已经明确。
