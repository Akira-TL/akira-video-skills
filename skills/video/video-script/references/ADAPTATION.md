# 小说 / 故事到视频改编

当视频来源于小说、章节、短篇故事、世界观资料或其他长文本叙事时使用。

目标不是把原文缩写成旁白，而是把当前目标时长内最重要的故事因果转换成**可被镜头表现的动作、场景和对白**。

## 1. 先固定改编范围

先明确：

- 当前视频改编哪些章节 / 段落；
- 目标时长；
- 观众是否已经知道世界观背景；
- 必须保留的事件、关系和信息；
- 可以压缩或省略的支线；
- 是否允许合并事件 / 场景 / 次要角色。

这些决定优先记录在 `VIDEO.md` 项目定义或 `SCRIPT.md` 的改编说明，不修改上游小说本身。

## 2. 保留来源 pointer

`SCRIPT.md` 记录当前场次 / 关键事件来自哪些上游章节或文件，便于后续检查人物、世界观和事实。

不要把整章小说复制进 `video/script/`。

## 3. 从文字叙事转换成可见行为

小说中的以下内容需要转译：

- 内心独白 → 表情、动作、选择、环境反应或必要对白；
- 大段背景说明 → 已存在的场景细节、角色行为或极少量必要信息；
- 作者总结 → 具体事件；
- 长时间过程 → 能代表过程变化的关键动作 / 镜头；
- 抽象情绪 → 可见的身体、语气、节奏和选择。

不是所有内心信息都必须“找一句台词说出来”。无法自然视觉化、又不影响当前短片理解的信息可以省略。

## 4. 压缩但不破坏因果

为了时长可以：

- 合并连续发生且作用相同的事件；
- 省略不影响当前因果链的支线；
- 用一个可见动作代表一段重复过程；
- 把多个地点压缩到更少场景，只要不改变必要因果。

但不能因为压缩让：

- 角色突然知道未知信息；
- 人物动机消失；
- 重要关系无来源改变；
- 世界规则与原作冲突；
- 关键结果没有前因。

## 5. 表现转换与事实改写分开

以下通常属于表现转换：

- 把内心活动改成动作；
- 调整对白长短；
- 在不改事实的前提下合并镜头 / 场景；
- 改变叙事顺序以适应短片，但仍能清楚建立因果。

如果要改变角色关系、事件结果、世界规则、关键动机或其他上游事实，明确作为改编决定，不静默当成“视频化”。需要用户决定的内容先讨论。

## 6. 长篇项目

小说很长时不预设整个视频项目必须建立复杂章节树。

当前视频只改编一个章节或片段时保持浅结构；只有多个章节 / 集数实际进入同一个视频制作项目、镜头数量已经难以平铺时，才在 `shots/` 内增加章节等组织层。

## 完成标准

不读原小说正文也能从视频脚本理解当前短片的因果链；需要核验人物 / 世界事实时又能沿 pointer 回到原始章节；脚本没有靠大量旁白复述小说。
