# 视频脚本层模板

这些模板用于当前项目确实需要对应文件时。不要为了模板完整创建空文件；简单项目可以只用其中一部分。

## 1. SCRIPT.md

回答“当前视频里发生什么”，不写详细摄影机和模型参数。

```markdown
# Script

## 改编来源

- 来源：<小说章节 / brief / 用户说明 / 无>
- 范围：<当前视频改编的部分>
- 明确改编决定：<如果有>

## 一句话梗概

<一句话说明人物 / 问题 / 变化>

## 核心因果

<问题>
→ <人物原有行动>
→ <后果 / 升级>
→ <选择 / 转折>
→ <结果>

## SC01

地点：LOC01
时间：早晨
目的：<这一场让什么发生 / 改变>

动作：
<按剧情顺序描述可见行动>

对白：
CHR01：……
CHR02：……

出口：
<这个场次结束时剧情 / 人物 / 道具发生什么变化>

## SC02
...
```

使用规则：

- 不为每个场次重复人物百科；
- 不写镜头焦段 / 具体生成提示词；
- 内心信息尽量转成可见行动 / 必要对白；
- 上游来源事实不静默改写。

## 2. CHARACTERS.md

回答“角色在本片怎么演”，不复制完整视觉设计。

```markdown
# Characters

## CHR01 — <角色名>

来源：<上游角色文件 / 小说章节 / 用户定义>
本片身份阶段：<如果有>
本片作用：<叙事功能>

目标：
<当前真正想得到什么>

担忧 / 阻力：
<害怕什么 / 什么让他受阻>

典型行动方式：
<遇到问题通常先做什么>

压力下反应：
<防御 / 逃避 / 攻击 / 沉默等>

表演范围：
- ...

禁止表演：
- ...

对白节奏：
<句长 / 语速 / 停顿 / 抢话 / 反问等>

声音：
→ `video/materials/voices/CHR01_voice.md`（存在时）

视觉设计：
→ `video/materials/characters/CHR01_design.md`（存在时）

本片变化：
<角色从开头到结尾真正改变什么；无则写无>
```

使用规则：

- 脸、发型、服装、材质、颜色等进入 `video-design`；
- 具体台词仍写在 `SCRIPT.md`；
- 同一个人物换服装不新增 CHR ID。

## 3. SCENES.md

回答“视频有哪些场次，它们在故事里做什么”，不是地点美术圣经。

```markdown
# Scenes

## SC01

地点：LOC01
时间：早晨

叙事目的：
<这个场次为什么存在>

出场：
- CHR01
- CHR02

入口状态：
<本场开始时必须知道的剧情 / 道具状态>

关键事件：
<当前场真正发生什么>

出口状态：
<本场结束时改变什么>

地点设计：
→ `video/materials/scenes/LOC01_design.md`

连续性重点：
<只写跨场次真正重要的内容>
```

使用规则：

- 同一 LOC 可以被多个 SC 复用；
- 白天 / 夜晚不是自动新地点；
- 完整材质、布局、光线规则由 `video-design` 拥有。

## 4. SHOTS.md

用于从头到尾快速阅读镜头计划，不替代每个镜头自己的 `SHOT.md`。

简单项目推荐表格：

```markdown
# Shots

| Shot | 目标时长 | 目的 | 主要画面 / 动作 | 连续性依赖 |
| --- | --- | --- | --- | --- |
| SC01_SH010 | 3–4s | 建立空间与人物 | CHR01 进入厨房 | 无 |
| SC01_SH020 | 4–5s | 发现问题 | CHR01 拿起皱衬衫 | SC01_SH010 |
| SC01_SH030 | 2–3s | 产品信息 | 产品操作特写 | 无 |
```

镜头较复杂时可以改成短段落：

```markdown
## SC01_SH020

目标时长：4–5 秒
目的：让 CHR01 明确发现问题
主要画面 / 动作：拿起皱衬衫，停顿，确认褶皱
连续性依赖：SC01_SH010 当前采用结果
```

使用规则：

- `SHOTS.md` 只做总览；
- 具体摄影、动作时间、参考素材、Continuity In / Out、硬性约束进入对应 `SHOT.md`；
- 不把每个生成结果 / 当前采用写回总表；
- 镜头数量与 coverage 属于 `video-shot`；真正需要展开 / 审核镜头覆盖时按需加载该 Skill，不在脚本模板复制第二套镜头方法，也不为表格完整凑镜头。

## 5. 文件可以很短

如果当前视频没有角色、没有剧情场次或用户已经给出完整镜头，不创建空 `CHARACTERS.md / SCENES.md / SCRIPT.md`。

模板是内容边界，不是文件清单。

## 完成标准

打开 `video/script/` 可以快速理解“当前视频发生什么、谁怎么演、有哪些场次和镜头”；具体视觉设计、摄影、提示词和生成结果不重复塞回脚本层。
