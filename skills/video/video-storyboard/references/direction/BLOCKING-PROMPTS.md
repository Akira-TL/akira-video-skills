# 场面调度（Blocking）参考提示词

场面调度（Blocking）参考图用于明确人物、道具、产品、摄影机与空间之间的站位和运动关系。它不是角色设定图，也不是最终美术图。

## 静态站位参考

```text
生成一个简化、清楚、可读的场面调度参考图。

场景：
<LOCxx 及当前世界空间方向>

角色站位：
- <CHR01>：<世界空间位置，例如北侧门内 1 米>；面向 <目标>
- <CHR02>：<世界空间位置>；面向 <目标>

道具 / 产品：
- <PROP01>：<世界空间位置>
- <PROD01>：<世界空间位置 / 朝向>

摄影关系：
- 主摄影轴：<方向>
- 摄影机位于轴线：<哪一侧>
- 画面左 / 右关系：<如有必要>

画面要求：
- 优先准确表达世界空间和角色站位
- 人物可以使用简化外观，但身份标记必须可区分
- 不重新设计角色服装、场景结构或产品
- 不随机交换人物左右
- 不镜像门窗和固定家具
- 不增加无关角色或道具
```

## 动作路径参考

需要规划移动时，在静态站位基础上增加：

```text
运动路径：
- CHR01：从 <A> 沿 <路径> 移动到 <B>
- CHR02：保持 <位置 / 状态>
- PROP01：由 <谁 / 哪只手> 从 <位置 A> 移动到 <位置 B>

关键接触点：
<递物 / 开门 / 操作产品 / 机械接触>

必须保持：
- 世界空间方向
- 角色自身左右
- 摄影轴
- 门窗 / 家具固定位置
- 动作前后可解释
```

## 与 Shot 的关系

Blocking 只解决“谁在哪里、朝向哪里、怎样移动、摄影轴在哪里”。最终镜头的景别、焦段、运动、曝光和镜头级用光仍由 Cinematography 完善；人物身份与环境结构仍来自已确认参考。

## 完成标准

下一步生成或摄影设计不需要再猜角色站位、世界空间方向、接触关系和摄影轴。
