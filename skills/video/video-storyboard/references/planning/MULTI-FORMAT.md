# 多画幅与构图适配

只有 `VIDEO.md` 明确要求多个画幅版本，例如 16:9 主片和 9:16 竖版时使用。

## 1. 先确定主版本与派生版本

在 `VIDEO.md` 交付要求中明确：

- 主画幅；
- 需要的其他画幅；
- 哪些版本允许直接裁切；
- 哪些版本必须重新构图 / 重新生成。

不要到最终导出时才第一次发现横版主体裁成竖版后已经看不见。

## 2. 可以共用一次生成的情况

如果一个镜头通过合理安全构图就能同时支持多个画幅：

- 主要人物 / 产品尽量处于共同可用区域；
- 关键动作不依赖极端左右边缘；
- 字幕 / Logo 留给后期安全区；
- 背景允许横向或纵向裁切。

这时优先生成一个主版本，再由 `video-editing` 适配派生画幅。

## 3. 不应该强行裁切的情况

以下情况优先分别设计构图：

- 横版依赖左右人物关系；
- 竖版需要上下空间或全身构图；
- 产品在主版本位于裁切边缘；
- 关键文字 / 道具 / 动作裁切后消失；
- 摄影运动方向在另一画幅中不成立。

如果构图语义已经改变，就不是简单“裁一下”，应为同一个镜头建立画幅专属生成版本。

## 4. 文件命名

镜头源文件和提示词的画幅后缀统一按 `akira-video/references/project/NAMING.md`；只有多个独立画幅源确实同时存在时才加后缀。

最终成片命名属于 `video-editing`；真正进入后期命名时按需加载该 Skill，不在 `video-shot` 维护第二套规则。

## 5. 角色 / 产品一致性

横版与竖版是同一个镜头设计的不同构图时，必须复用相同：

- 人物身份；
- 服装 / 状态；
- 产品结构；
- 场景设计；
- 主要动作与剧情结果。

画幅变化不能变成重新随机设计角色或产品。

## 6. 审片

派生裁切版本至少检查：

- 主体没有被切断；
- 产品 / 道具仍能读清；
- 视线 / 人物关系仍成立；
- 动作没有越出有效区域；
- 字幕 / Logo 后期安全区足够。

重新生成的画幅专属版本按普通镜头生成结果进行完整 `video-review`。

## 完成标准

多画幅需求在镜头设计阶段已经被考虑；能够裁切的直接派生，不能裁切的重新构图，不靠后期硬裁毁掉叙事或产品可读性。
