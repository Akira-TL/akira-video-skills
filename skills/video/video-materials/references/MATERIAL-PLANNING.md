# 复用素材规划

在正式批量生成人物、场景、道具或产品参考图之前使用。

## 1. 从真实镜头需求反推

读取当前脚本、镜头总览和已经明确的镜头，列出哪些对象会跨多个镜头重复出现，哪些对象的身份 / 结构容易漂移。

不要为了“素材库完整”预生成所有角色、所有道具、所有可能状态。

角色 / 场景已经完成视觉设计时，先读取 `video-design/references/foundation/DESIGN-OUTPUTS.md` 理解哪些参考是基础身份、状态或镜头专属内容，再决定当前项目真正需要生成哪些长期素材。

## 2. 只规划长期复用对象

适合成为复用素材的典型情况：

- 主要或重复出现的人物；
- 多镜头共享的服装状态；
- 多镜头共享的主要场景；
- 结构必须保持的道具；
- 广告产品及官方结构参考；
- 整片持续使用的视觉方向或风格参考；
- 跨镜头稳定的角色声音参考。

只在单个镜头出现的一次性光效、临时道具、特殊姿势、局部烟雾等，优先留在镜头，不升级成公共素材。

## 3. 先复用已有素材

每次新增素材前先检查：

- 是否已经有同一身份 / 状态的长期参考；
- 现有参考是否足以支持当前镜头；
- 是否只需要补一个新状态，而不是重新生成整个对象；
- 新图是否会和已有图竞争身份。

## 4. 优先级

需要规划多项素材时，可以按三档判断，但不要求建立正式数据库：

- **必须先有**：没有它就无法稳定生成后续镜头；
- **明显提高一致性**：可以先做，但不是硬 blocker；
- **可选**：只有实际失败或后续需求出现时再生成。

原稿中 P0 / P1 / P2 的思想保留在这里作为制作优先级，不要求项目创建额外 manifest。

## 5. 状态拆分

同一对象只有在剧情或镜头确实需要不同状态时才拆，例如：

- costume-a / costume-b；
- normal / damaged；
- dry / wet；
- closed / opened。

不同状态继续继承同一基础身份设计。

## 6. 人类可读索引

素材很少时直接浏览目录即可。

只有当 `video/materials/` 已经多到难以查找时，才增加一个简短 `README.md` 作为索引；不要默认建立复杂 `ASSET_MANIFEST` 或机器数据库。

## 完成标准

后续镜头真正需要稳定的对象有足够长期参考，同时没有为了数量制造大量没人会用的素材。
