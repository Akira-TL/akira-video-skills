# 通用生图 Prompt 规则

本文件定义 Akira Video 自己的长期图片 Prompt 规则，不绑定具体图片生成模型。

## 1. Prompt 来源

生图 Prompt 必须从已经确认的设计和事实来源编译：

- 角色：`*_design.md`；
- 场景：场景设计 / 世界规则；
- 产品：官方产品事实与官方结构参考；
- 道具：当前长期结构说明；
- 视觉方向：项目已有视觉方向。

如果角色 / 场景仍只有泛化功能描述，先进入 `video-design`。

## 2. 基础结构

按对象需要组织：

对象身份 / 类型
→ 稳定外形与结构
→ 当前状态
→ 服装 / 材质 / 颜色
→ 视角与构图
→ 背景
→ 光线
→ 画面类型 / 现实程度
→ 必要禁止项。

不是每个 Prompt 都必须机械写满全部字段。

## 3. 身份参考图

身份参考图优先：

- 中性表情；
- 容易辨认的姿态；
- 清楚的轮廓；
- 稳定的服装 / 材质；
- 简洁背景；
- 不加入剧情动作；
- 不加入只属于某个 Shot 的临时道具。

## 4. 场景参考图

场景参考图优先稳定空间、材质、色彩和光线，不加入人物剧情动作。需要严格空间参考时使用场景四视图。

## 5. 产品 / 道具参考图

产品和结构性道具优先保持工业结构与部件数量。具体产品事实来自 `video-advertising` / 官方素材，生成 Prompt 不能补造未知结构。

## 6. 严格四视图

当前对象需要四视图时，不自行改写模板结构：

1. 从已确认设计提取对象具体描述；
2. 把具体描述与 `FOUR-VIEW-PROMPTS.md` 对应模板组合；
3. 保留模板要求的 1:1、2×2、固定视角和禁止项；
4. 不把模型特定参数写进长期通用 Prompt；
5. 返回图先经 `video-review` 检查四格一致性。

## 7. 文字和 Logo

除非参考图本身的任务就是核验官方文字 / Logo，否则生成参考图尽量不依赖模型准确生成文字。

正式 Logo、型号、参数和长文本优先由官方文件或后期确定性合成。

## 8. Prompt 版本

长期 Prompt 与对象素材共置，例如 `CHR01_prompt.md`。

如果同一对象的 Prompt 只是小幅修订，由 Git 保存历史即可；只有项目确实需要同时保留多个可比较 Prompt 时，再使用清楚的 `prompt_v01.md` / `prompt_v02.md`。

## 完成标准

Prompt 能从设计稳定地产生需要的参考图，而不是每次重新随机设计对象；模型换掉后，长期 Prompt 的核心身份和结构仍然可复用。
