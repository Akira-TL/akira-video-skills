# 严格四视图生图模板

这些模板用于建立可跨镜头复用的稳定参考图。只有当前对象需要稳定身份、结构或空间时使用；一旦使用对应模板，就遵守该模板的固定版式和一致性要求，不自行改成“自由多视角”。

## 1. 人物四视图

```text
生成一张 1:1 正方形人物设定图。

严格 2×2 四格等大排列。

白色背景。
均匀柔光。
无标题。
无文字。
无编号。
无 Logo。
无水印。

左上：
人物正面头部近景。
完整展示唯一面部设计。
中性表情。

右上：
人物 180° 后脑勺。
完整展示发型结构。
禁止侧脸。

左下：
正面头到脚全身。
人物完整。
手脚不得裁切。
面部区域不画眼睛、眉毛、鼻子、嘴巴。
不得使用模糊、马赛克、黑块或面具代替。

右下：
严格右侧头到脚全身。
完整身体和发型轮廓。
面部区域同样没有任何五官。

同一人物：
- 发型一致
- 身高比例一致
- 服装一致
- 配件位置一致
- 颜色一致

禁止：
多个不同人物
不同服装
不同年龄
不同发型
下方全身图出现五官
过度表情
剧情动作
额外道具
```

## 2. 衣物角色四视图

适用于衣物本身被拟人化、具有角色面部的设计。

```text
生成 1:1、2×2 衣物角色设定图。

左上：
领口 + 上胸角色面部细节。

右上：
后领 + 背部材质。

左下：
完整正面衣物。
必须无脸。

右下：
严格右侧完整衣物。
必须无脸。

衣物为空心。
不要人体。
不要人台。
不要真人头。
不要脖子。
不要手指。
不要腿。

角色表情只允许存在于左上细节格。

四格必须保持：
剪裁
扣子数量
领口
袖口
材质
颜色
衣架
完全一致。
```

## 3. 普通衣物四视图

```text
现实服装。

1:1。
2×2。
照片级真实摄影。

四格全部禁止五官。

左上：
领口、上胸、材质细节。

右上：
后领、背部材质。

左下：
完整正面。

右下：
严格右侧。

同一件衣服。
同一状态。

禁止：
人体
人台
头
手
脚
拟人表情
改变剪裁
不同颜色
不同扣子数量
```

## 4. 道具四视图

```text
生成 1:1、2×2 道具参考图。

左上：
关键正面结构细节。

右上：
关键背面或连接结构。

左下：
完整正面。

右下：
严格右侧。

四格必须是：
同一物体
同一状态
同一比例
同一结构

不得：
增加不存在的接口
改变部件数量
增加装饰
强行拟人
写文字
生成 Logo
```

## 5. 场景四视图

```text
生成 1:1、2×2 场景设定图。

四格必须是同一个三维空间。
不是四套类似房间。

固定摄像机高度。
固定等效焦段。
固定地平线。

左上：
从前向后。

右上：
从后向前。

左下：
从右向左。

右下：
从左向右。

必须保持一致：
门数量
门位置
窗数量
窗位置
主要家具位置
墙体关系
主光方向

禁止：
镜像替代反面
不同家具布局
随机增加物件
人物
剧情动作
```

## 使用规则

- 四视图 Prompt 应从已经确认的 `*_design.md` 和当前对象长期 Prompt 中填入具体角色 / 场景 / 道具设计，不用模板本身替代设计。
- 同一对象不同状态分别生成，不让一张四视图同时代表多个状态。
- 返回结果先由 `video-review` 检查四格是否真的是同一身份 / 结构 / 空间，再作为长期参考素材。
