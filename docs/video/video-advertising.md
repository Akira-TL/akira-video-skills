# video-advertising

`video-advertising` 是品牌短片、产品植入剧情和广告项目的可选领域 Skill。

它把产品事实文件与官方产品素材放在 `video/materials/products/`，并按 `references/PRODUCT-TRUTH.md` 区分已经证明、需要谨慎表达和当前未知的产品能力；AI 生成参考不能反向成为产品事实。真实产品镜头按 `references/PRODUCT-SHOTS.md` 优先使用官方图、轻运动和确定性后期，结构不稳定时宁可 2.5D / 合成也不重画成错误产品。剧情广告还会检查产品是否自然解决已经建立的问题，以及最终品牌落版是否只使用已证实信息。
