# video-review

`video-review` 审核返回项目的复用素材和镜头生成结果。判断必须基于实际返回 artifact；当前执行器无法查看完整视频 / 声音时明确未验收维度，不根据提示词推断“已经正确”。媒体元数据、SHA-256、视频均匀抽样帧与严格 2×2 图片四象限切图优先使用 Skill 自带 `scripts/media_review.py`；这些都只是审片辅助，不能替代完整播放、听音、口型或人物 / 场景内容判断，机械分格成功也不等于严格四视图语义通过。

它根据正式人物/场景/产品定义、`SHOT.md`、提示词和相邻连续性判断：采用、接受偏差并调整后续、后期修复、重新生成，还是重写定义/提示词。明显失败先按 `references/FAILURE-MODES.md` 定位，再按 `references/REPAIR-DECISIONS.md` 选择成本和确定性最合理的修复路径；连续失败会升级到简化 / 拆镜头或回到上游，而不是无限抽样。一次返回多个候选时按 `references/CANDIDATE-SELECTION.md` 先淘汰硬错误；“最好看的一条”也可以全部不合格。详细人物、空间、声音、摄影和产品检查按 `references/TAKE-QA.md` 展开。采用哪个生成结果记录在镜头自己的 `SHOT.md` 中，并保留实际出口、可接受偏差和后期修复项；不复制 `final.mp4`，也不建立额外选择数据库。
