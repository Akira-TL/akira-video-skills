# video-script

`video-script` 把小说、章节、故事梗概、品牌要求或其他上游内容转换成当前 `Vxxx` 的正式剧情、动作、对白与旁白。上游原文继续由原体系拥有，视频只记录本次采用 / 改编范围和正式视频化内容。

短视频可以直接在 `Vxxx/VIDEO.md` 维护剧情、动作、对白与场景顺序；内容变长影响阅读时再拆到 `Vxxx/scenes/SCxx.md`。拆出后 `VIDEO.md` 只保留概要、顺序和链接，同一句对白或动作不维护第二份副本。

有剧情时优先保证事件因果、人物选择和对白连续性；重要情绪变化要转成可观察的身体、视线、动作与行为节拍。存在可见对白、长台词、多角色说话或同步口型时，再检查自然语速、镜头时长和说话人关系。角色声音身份交给 `video-audio`，详细 Shot 划分交给 `video-storyboard`。
